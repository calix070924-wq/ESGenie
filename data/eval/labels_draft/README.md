## 규칙

1. **B 독립 라벨 제출 전에는 이 폴더를 B에게 전달하지 않는다.** B의 독립성이 깨진다.
   빌더(`scripts/build_b_package.py`)의 금지 경로에 `data/eval/labels_draft/`를 넣어
   패키지에 들어가지 못하게 했다.
2. `labeler` 열에는 **사람 이름을 넣지 않는다.** 초안 행은 `AI초안_미승인`이다.
   사람이 검토·승인한 행이 생기면 그때 그 사람이 직접 자기 이름을 적는다.
3. 채점은 **확정 라벨을 먼저 커밋한 뒤** 돌린다. 이 초안으로 채점하지 않는다.
4. 채점 결과나 시스템 응답을 보고 이 초안을 고치지 않는다. 작성 시점에 A는 어느 실행의
   ESGenie 응답도 읽지 않았다(아래 §작성 근거).

| | 고유 행 | 파일 행 |
|---|---|---|
| 전체 | 96 | 98 |
| 확인 대기 | **16** | 18 |
| 쟁점 없음 | 80 | 80 |

**쟁점 없음 80행도 승인 완료가 아니다.** 쟁점이 없다는 것은 "A 초안 작성 중에 선택지가

| 기준 | 내용 |
|---|---|
| initial / followup 분리 | initial 라벨에 보완 증빙(13번)을 섞지 않았다. followup 행은 13번을 포함해 다시 판단했고, 바뀌지 않은 문항은 그 이유를 `note`에 적었다 |
| `00_` 안내 PDF | 맥락 참고용으로만 읽었다. **업로드 증빙으로 치지 않는다** → `expected_sources`에 넣지 않았다 |
| `05_` 자가진단 초안 | **회사 자가주장이다.** 그 자체를 검증된 정답 근거로 쓰지 않았다 → `expected_sources`에 넣지 않았다 |

| 미보유를 0으로 적지 않기 | 자료가 없으면 `hold`/`no_evidence`다. `0`·`0%`로 적으면 측정 결과라는 뜻이 된다 |
| **증빙 부재 ≠ 미이행** | 어느 요건의 증빙이 없다는 사실만으로 `answer`(아니오)로 확정하지 않는다. `hold`로 두고 무엇이 없는지 적는다. 회사가 실제로 이행하지 않았다는 판정은 이 자료로 할 수 없다 |

### `hold_reason` 선택 규칙 (2026-10-06 정정)

**정정 전:** 요건이 일부만 입증된 행 40건을 `needs_human_text`로 분류했다. 그것은
**잘못이다** — 단순한 증빙 부족을 사람의 서술 판단이 필요한 경우로 섞었다.

**정정한 규칙** (위에서 아래로 처음 맞는 것을 쓴다):

| 순위 | 사유 | 적용 조건 |
|---|---|---|
| ① | `no_evidence` | **미확인 요건의 증빙이 세트에 없다.** 요건 전부가 비었든 일부만 비었든 같다 — 가장 근본적인 결손이다 |
| ② | `scope_unconfirmed` | 모든 요건의 증빙은 있으나 **기간·사업장·대상 범위**가 문항·요청서와 맞는지 확인되지 않는다 |
| ③ | `not_comparable` | 자료는 있으나 요청 **측정량·단위**로 환산·비교할 수 없다(환산계수 부재 등) |
| ④ | `needs_human_text` | **증빙이 요건을 덮는데** 남은 판단이 값 대조가 아니라 사람의 **서술·충분성** 판단이다 |

**정정 결과: 66행 전부 `no_evidence`다.** 33문항 모두 미확인 요건의 증빙이 세트에
없다. 이 통일은 **규칙에서 나온 결과**이고, 행별로 어떤 요건이 입증되고 어떤 요건의
증빙이 없는지는 `boundary_note`에 `입증:` / `미확인:`으로 **나눠 적어 두었다**(원칙 ②).
②③④에 해당하는 행은 이 33문항에 **없다.**

요건 일부만 입증된 상태를 enum으로 구분하려면(`partial_evidence` 등) 라벨 열 계약을
바꿔야 하므로 지민 결정과 B 합의가 필요하다. **임의로 추가하지 않았다.**

## 사람 확인이 필요한 행

`note`가 `확인요청`으로 시작하는 행이다. 원본 파일·페이지와 판단 이유를 그 행에 함께
적어 두었다. 세 문서로 나뉘어 있고 **앞 문서의 표를 반복하지 않는다.**

| 문서 | 담는 것 |
|---|---|
| `docs/라벨초안_확인요청_2026-10-06.md` | 1차 — 확인 대기 행 목록과 쟁점 |

  근무 인원이라 문항의 '이해관계자' 대상이 빠진다.

- `06` 제1조("일부 월 값을 연간 실적으로 표시하지 않는다")는 **에너지·용수 조항**이다.

3차에서 바뀐 것 — **요청서를 읽고 A 의견 2건을 철회했다:**

  입증하지 않는다.

  Scope 1·2를 요청했고 `01`이 그 산정자료 부재를 직접 적는다 → 결손은 자료 부재다.

초안 행의 값은 **승인 전이므로 하나도 고치지 않았다.**
