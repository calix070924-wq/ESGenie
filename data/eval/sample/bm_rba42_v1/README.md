# 독립 라벨링 표본 bm_rba42_v1 (2026-10-06)

**이 디렉터리에는 정답이 없다.** A의 정답 라벨도 ESGenie 응답도 들어 있지 않다.

- 양식 `rba42` 48문항, 단계별 10문항 × 2단계 = **20행** (전체 96행의 20.8%).
- 유형별 층화 후 정렬된 문항 ID에서 **씨값 20261006**으로 추출. 단계마다 같은 문항.
- 시스템의 정오답·보류 여부는 추출에 쓰지 않았다
  (`scripts/eval_label_sample.py`는 응답·라벨 파일을 입력으로 받지 않는다).

| 파일 | 내용 |
|---|---|
| `sample.json` | 추출 결과와 방법·씨값·대상 목록 지문 |
| `questions.csv` | 표본 문항 정의 (정답은 없다) |
| `labels_blank.csv` | 빈 라벨 서식 20행 (`stage`·`qid`만 채워져 있다) |

채우는 방법과 독립성 규칙: `docs/독립라벨링_표본패키지_B_2026-10-06.md`.

재현:

```bash
python scripts/eval_label_sample.py --seed 20261006 --out <다른_경로>
```

빈 서식을 그대로 채점기에 넣으면 `LabelError`로 거부된다(기본값을 넣지 않았다).
완성된 라벨은 이 디렉터리가 아니라 `data/eval/labels/`에 둔다.
