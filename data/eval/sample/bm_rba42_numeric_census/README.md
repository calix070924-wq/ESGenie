# 수치형 전수 검토 집합 bm_rba42_numeric_census (2026-10-06)

**이 디렉터리에는 정답이 없다.**

공식 무작위 표본(`bm_rba42_v1`)과 **별개의 집합**이다. 결과를 합치지 않는다.

- 양식 `rba42`의 **수치형 6문항 전수** × 2단계 = **12행**. 무작위가 아니므로 씨값이 없다.
- 왜 전수인가: 수치형이 6문항뿐이어서 비율 표본으로는 단계별 1문항만 들어온다.
  값·단위·측정 경계 비교가 걸리는 부분이라 전수로 본다.
- **왜 분리 보고인가:** 전수 집합은 모집단을 대표하지 않는다. 공식 표본의 일치율에
  섞으면 수치형이 과대 가중되어 공식 수치가 왜곡된다.

## 겹치는 행은 재사용한다

| 항목 | 값 |
|---|---|
| 공식 표본과 겹치는 문항 | `RBA-C-8-E-3-1` (1문항 × 2단계 = 2행) |
| 새로 라벨을 매길 문항 | 5문항 × 2단계 = **10행** |

`labels_blank.csv`에는 **새로 매길 10행만** 들어 있다. 겹친 문항은 같은 문항·같은
단계·같은 원본이므로 공식 표본에서 매긴 라벨을 그대로 쓴다. 두 번 매기지 않는다.

## 파일

| 파일 | 내용 |
|---|---|
| `sample.json` | 전수 대상, 겹침 표시(`overlap_with`), 새로 매길 목록(`labels_needed_qids`) |
| `questions.csv` | 수치형 6문항 정의 (정답은 없다) |
| `labels_blank.csv` | 빈 라벨 서식 10행 |

재현:

```bash
python scripts/eval_label_sample.py --mode census --qtype numeric \
  --overlap-with data/eval/sample/bm_rba42_v1/sample.json \
  --out <다른_경로>
```

적혀 있는 문항이다. 전수이므로 빼지 않고 포함했다. 이 문항의 독립 검토 인정 여부는
