## 원인과 수정

저장된 `self_reports.boundary.site_path`는 JSON 목록이고 실제 회사 답변 파서의 새 결과는 튜플이다. 기존 `reconcile()`의 직접 비교는 같은 사업장 경로를 변경으로 판단했다.

비교 시에만 사본을 재귀적으로 만들어 목록과 튜플을 같은 순서의 목록으로 비교한다. 객체 필드 삽입 순서는 사전의 기존 동등 비교로 무시한다. 원본 자동 결과·회사 주장·담당자 저장값은 변경하지 않으며, 어떤 목록도 정렬하거나 문자열로 치환하지 않는다. 근거 순서를 무시한다는 공용 계약이 없으므로 근거 순서도 유지한다.

실제 변경 검사를 추가하면서 기존 비교 대상에서 빠진 기간, 구조화된 범위, 완전성, 비교 판정과 상세 결과, 판단 이유·플래그·추가 자료 요구, 선택지 근거와 초안·인용·근거 게이트도 확인했다. 이 필드가 실제로 바뀌면 재검토를 표시한다. 표시용 파생 필드는 별도로 비교하지 않는다.

기존 파일 교체 무효화는 그대로 유지한다. 동일한 PDF 바이트를 같은 이름으로 교체해 자동 값이 같아도 완료로 복구하지 않는다. 담당자가 직접 연결한 다른 원문을 교체한 경우도 같은 규칙을 유지한다. 담당자 값·범위·원문 연결·메모·수정 이유·기존 검토 이력을 덮어쓰지 않는다.
