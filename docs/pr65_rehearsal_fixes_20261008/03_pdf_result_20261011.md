## 원인과 수정

1. 제목은 HTML 이스케이프만 수행해 번들 폰트에 없는 `㈜`가 깨졌다. 제목·본문·부가 안내를 같은 `para()`로 처리해 기존 `pdf_safe_text()`의 `㈜ → (주)` 치환과 HTML 이스케이프·줄바꿈을 적용했다. 회사명을 지우지 않는다.
2. 긴 표 셀이 나뉘면 먼저 끝난 문항 번호 셀은 다음 페이지에서 비었다. 표 분할마다 문항 ID를 별도로 넘겨, 문항 중간에서 이어지는 페이지 머리글에 `RBA-E-2 (계속)` 같은 문항 식별자를 표시한다. 질문 셀 자체가 긴 경우도 원문을 모두 이어서 출력한다.
3. 행 내부 분할 후 남은 높이에 이어지는 표가 들어가 머리글이 페이지 중간에 반복됐다. 분할된 표 사이에 명시적으로 페이지 경계를 둔다. 새 페이지는 머리글을 한 번 출력하고 문항 경계에서는 일반 머리글로 돌아온다.
4. 고정 표 너비 793pt는 문서 폭과 같지만 내부 프레임 여백 12pt를 포함하지 않았다. 실제 인쇄 가능 폭 781.89pt에 맞춰 열 너비만 비례 조정했다. 글자 크기 8pt·행 간격 12pt는 유지한다.
5. 보완 대상 근거는 파일명만 출력했다. PDF에서도 페이지·버전·인용을 함께 보존하며 ‘값 산정 미사용’ 표시는 유지한다.

저장된 답변·값·범위·검토 상태·근거 판단·메모·수정 이유는 바꾸지 않는다. PDF 조회 전후 프로젝트 저장값이 같은 것도 확인했다.
