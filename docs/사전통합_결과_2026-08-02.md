# 코드 배정 사전 통합 결과 (2026-08-02)

## 구현 결과

- `evidence_graph._HINT_TO_KESG`를 제거했다.
- `_resolve_kesg_code`는 `kesg_items.resolve_kesg_code` exact alias를 1차 후보로 사용한다.
- exact alias가 LLM guess보다 우선하므로 `총 Scope 3 배출량`의 E-3-1 오추정은 E-3-2로
  교정된다.
- fuzzy는 생산 경로와 `_backfill_kesg_codes`에서 거부한다. 측정 전용
  `allow_fuzzy=True`만 남겼다.
- 부분 exact는 leftmost-longest다. 동길이면 먼저 등장한 별칭이 이겨 설명문 뒤의 Scope 1/2가
  앞의 Scope 3 지표명을 뒤집지 않는다.
- G1 가드, G3 단위정합, G4 미래기간, G6 각주 배제와 지정폐기물 중복가드는 유지했다.
- 실측 표기 호환을 위해 `tCO2e`를 `tCO2eq`와 동치 처리하고, 용수 E-5-1에 한해서만 m³와
  K-ESG 정의의 ton 병용을 허용했다.
- GRI 번호·표 머리글 같은 비 K-ESG guess는 반환하지 않는다.

`search_terms`는 기존 순서를 바꾸지 않고 각 tuple 끝에만 추가했다.

- E-6-1: `폐기물 발생량`
- S-3-1: `여성 직원 비율`
- G-2-1: `이사 출석률`, `이사 평균 참석률`

## 라이브 검증 인계

요청에 따라 라이브 API는 호출하지 않았다. 사용자가 캐시 히트 경로로 다음을 실행한다.

```bash
for t in 012330 009150 051910 055550 035420; do
  python3 scripts/inspect_ledger_provenance.py --ticker $t --areas E S G --json outputs/lp7_${t}.json
done
```
