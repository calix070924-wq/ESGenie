## 1. 조사가 바꾼 계획 3가지

지시서 대비 실측이 정정한 부분이다.

### (1) 분모는 고치지 않는다 — 실측이 주석을 반박

주석("4개 = 만점")과 코드(분모 1.0)가 어긋난 건 사실이지만, **틀린 쪽은 주석이다.**
분모를 4로 올리면:

| D2 정의 | dev F1 | **test F1 (held-out)** |
|---|---|---|
| 현행 (분모 1.0) | 0.808 | **0.532** |
| 분모 4 (주석 의도) | 0.933 ↑ | **0.255** ↓↓ (recall 0.494 → 0.157) |

test 양성 83건 중 **41건이 모호어 1~2개**다. 분모 4면 히트 1개 → 0.25로
`axis_flag=0.80`을 못 넘고 D2 가중치 0.25로는 `threshold=0.25`도 못 넘어 TP 41 → 13.
dev만 오르고 held-out은 무너지는, 전형적인 튜닝셋 과적합 패턴이다.

`D2_THRESHOLD`가 `calibrate.py` 그리드에 없어 직접 튜닝된 기록은 없으나,
`axis_flag=0.80`이 분모=1인 D2 분포 위에서 튜닝됐다. **코드는 그대로 두고 주석을
실제 동작 + 실측 근거로 교체**했다(`layer3_detect.py:557`).

### (2) `search_terms`는 면제 출처로 쓸 수 없다

지시서는 "`name`(+필요시 `search_terms`)"라고 했지만, `search_terms`를 쓰면
**벤치 양성이 깨진다**:

```
GOLD-40 (greenwash) "친환경 인증 침대로 가족 건강을 지키세요"
  ← E-9-1 search_term '친환경 인증'과 완전 일치 → 통째로 면제
```

항목명(`친환경 인증 제품/서비스`)은 그 자체로 K-ESG 지표 참조라 오인 소지가 없지만,
`search_terms`는 광고 문구와도 겹치는 짧은 표현이다. **`name`만** 쓴다.
회귀 테스트로 고정: `test_bench_positive_not_exempted_by_search_term`.

### (3) E-1-1은 자책골 경로가 아니다

조사 중 `탄소중립 목표`가 겹치는 걸 발견해 "E-9-1 외 1건 더"로 봤으나, 재확인 결과
E-1-1의 `name`은 `환경경영 목표 수립`(모호어 없음)이고 `탄소중립 목표`는 `search_terms`다.
`name` 기준 겹침은 **E-9-1 단 1건**으로, 지시서 판단이 맞았다.
`탄소중립 목표 항목의 공개가 필요하다`는 (2)의 이유로 **여전히 발화한다** —
이것도 테스트로 고정했다.

## 2. 구현

`esgenie/knowledge/greenwash_lexicon.py` — 검출기만 손댔고 **어휘 사전은 그대로**다.

### 2-1. (나) K-ESG 항목명 구간 면제

```python
def _kesg_item_name_spans(sentence: str) -> list[tuple[int, int]]:
    """문장에 **항목명 전체**가 나타난 구간 목록."""
```

`kesg_items.ALL_ITEMS`의 `name`을 단일 출처로 쓴다(토픽 인덱스 `_build_topic_terms`와
같은 출처). 항목명 **전체**가 문장에 나타난 구간만 면제하므로, `친환경`이 항목명 밖에서
쓰이면 그대로 잡힌다.

구분자 변형(`_name_variants`)도 흡수한다 — 정의는 `친환경 인증 제품/서비스`인데
Phase 1 v2 본문은 `친환경 인증 제품 및 서비스`로 쓴다. `/` → `및` / `,` / 공백.

### 2-2. (다) 조직 접미 면제

```python
_ORG_SUFFIXES = ("추진팀", "추진단", "추진실", "위원회", "협의체", "본부",
                 "센터", "사업부", "팀", "부", "실", "국", "과")
```

모호어 **직후에 바로 붙은** 경우만 면제. `_ORG_SUFFIX_RE.match(sentence, end)`로
정확히 매칭 끝 위치에서만 검사하니 공백이 끼면 면제되지 않는다.

```
탄소중립추진팀 중심으로   → 면제 (부서명)
탄소중립을 추진하고 있다   → 발화 (주장)
탄소중립 달성을 위해      → 발화 (공백)
```

### 2-3. 면제 판정 단위 = 출현별

한 표현이 문장에 여러 번 나올 수 있다. **모든 출현이 면제 문맥일 때만** 히트에서
빠진다 — 자유로운 출현이 하나라도 있으면 잡는다. 라이브 문장 2가 이 케이스다:
`탄소중립추진팀`(면제) + `친환경 원부자재`(자유) → `친환경`만 히트.

## 3. 분모 관련 코드 변경

`esgenie/layer3_detect.py` — **로직 변경 없음**, 주석만 교체:

```python
# 분모는 `D2_THRESHOLD=0.25` 하에서 항상 1.0으로 접힌다 → **히트 1개면 만점**이다.
# 옛 주석은 "4개 = 만점"이라 코드와 어긋났는데, 실측 결과 **코드가 맞고 주석이 틀렸다**:
# 분모를 4로 올리면 held-out test 룰 단독 F1이 0.532 → 0.255로 반토막 난다
# ...
density = len(hits) / max(D2_THRESHOLD * 4, 1)
```

`TestDenominatorUnchanged`가 `max(D2_THRESHOLD*4, 1) == 1.0`과 "히트 1개 → 1.0"을
고정한다. 이 테스트가 깨지면 벤치 F1을 다시 재야 한다는 신호다.

**이월 (§5 of 영향조사):** 분모=1은 정보량 없는 이진 검출기(히트 1개와 5개가 같은 점수)라
개선 여지가 있다. 다만 방향은 분모 상향이 아니라 **카테고리 가중** —
`match_categories`가 이미 absolute/condition/abstract/vague를 나누는데 점수는 개수만 센다.
`탄소중립`(absolute) 1개와 `적극적`(vague) 1개가 같은 1.0인 게 실제 문제다.
착수 조건: held-out test 실키 전건(n=270) capture.
