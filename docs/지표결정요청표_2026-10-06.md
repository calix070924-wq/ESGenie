# 지표 산식 결정 요청표 (2026-10-06)

**한 번에 판단할 수 있게 한 표로 모았다.** 아래 D1~D5만 결정하면 지표를 산출할 수 있다.
결정 전까지 **코드에 적용하지 않는다.** 현재 채점기는 건수만 내고 비율은 내지 않는다.

이미 확정된 요구사항은 승인 대상에 올리지 않았다 — §3에 따로 적었다.

## 1. 결정이 필요한 다섯 가지

| # | 지표 | A의 제안 산식 | `na` | 누락 행 | `unparsed` | `unresolved` | 선택에 따른 영향 |
|---|---|---|---|---|---|---|---|
| **D1** | **답변·근거 정확성** | 분자 = `value_match=match` **그리고** `source_match=match`인 행. 분모 = 라벨이 `answer`인 행 중 응답 행이 있는 것 | 분모 제외 | **분모에 포함** (답을 못 낸 것도 결과다) | 분모 포함·분자 제외 | **분모 제외**, 건수 별도 표기 | 근거 일치를 분자에 **넣으면** 값만 맞고 근거가 틀린 행이 오답이 된다 → 수치가 낮아지지만 "정답"의 뜻이 선다. 안 넣으면 값 일치율이 되고 §8 금지("값 일치를 곧 정확성이라 부르지 않는다")에 걸린다 |
| **D2** | **자동 응답률** | 분자 = 응답 판정이 `confirmed` 또는 `unverified_submitted`인 행. 분모 = 전체 48행 × 단계 | **분모 포함** | 분모 포함·분자 제외 | 분모 포함·분자 제외 | 분모 포함·분자 제외 | `unverified_submitted`를 분자에 **넣으면** "값을 냈다"의 비율(높게 나옴), 빼면 "검증까지 했다"의 비율(낮게 나옴). **둘을 같은 이름으로 쓰면 안 된다.** A는 둘을 나눠 두 수치로 내는 것을 권한다 |
| **D3** | **자료 연결률** | 분자 = `evidence`가 1건 이상인 행. 분모 = 값을 제출한 행(`confirmed`+`unverified_submitted`) | 분모 제외 | 분모 제외 | 분모 제외 | 분모 포함 가능 | 분모를 **전체 48행**으로 하면 보류가 많을 때 낮게 나오고, **값 제출 행**으로 하면 "낸 답에 근거를 달았는가"가 된다. 보고서 문장이 달라진다 |
| **D4** | **연결한 근거가 정답인 비율** | 분자 = `source_match=match`. 분모 = `evidence`가 1건 이상이고 라벨에 `expected_sources`가 있는 행 | 분모 제외 | 분모 제외 | 분모 제외 | 분모 제외 | **D3과 같은 것이 아니다.** 근거를 전부 달았으나 전부 틀리면 D3 = 100%, D4 = 0%다. 한 수치로 합치면 이 구분이 사라진다 |
| **D5** | **반복 5회를 하나로 보는 방법** | 합치지 않는다. 실행별 수치를 나열하고 **최솟값·최댓값·편차**를 함께 적는다 | — | — | — | — | 평균 하나로 내면 편차가 숨는다. 1회 결과의 정확성을 먼저 해석할 수 있어야 평균이 뜻을 가진다 |

공통 제안: **모든 비율에 분자·분모 건수를 같이 적는다**(`12/20`처럼). 분모가 줄었으면
줄었다고 적는다. **산출 불가는 "산출 불가"로 적고 0으로 적지 않는다.**

## 2. 분모 단위 — 함께 정해야 하는 것

| 항목 | 선택지 | A의 제안 |
|---|---|---|
| 집계 단위 | 단계별(48행) / 전체(96행) / 둘 다 | **둘 다.** 단계별이 기본이고 전체는 참고 |
| 검토 집합 | 공식 표본 / 수치형 전수 / 합산 | **분리.** 합산하지 않는다(이미 확정된 지시) |
| 시스템 비교 | ESGenie 대조군 각각 / 차이값 | 각각 낸 뒤 비교. 차이값만 내지 않는다 |

## 3. 이미 확정된 것 — 승인 대상이 아니다

다시 결정할 필요가 없다. 참고용으로만 적는다.

| 항목 | 근거 |
|---|---|
| 잘못된 확정 수, 불필요한 보류 수는 **건수**로 낸다 | 작업지시서 A §6.2의 네 줄. 이미 구현·검증됨 |
| `unverified_submitted` 행의 집계 네 줄 | 같음 |
| 단위·기간·대상 차이를 정규화로 숨기지 않는다 | 작업지시서 A §7 금지 규칙 |
| 값 일치 건수를 곧 최종 답변 정확성이라 부르지 않는다 | 기존 지시 |
| 지표를 하나의 종합 점수로 합치지 않는다 | 기존 지시 |
| 노출 확인 행은 독립 일치율 분자·분모에서 제외 | 2026-10-06 정민 지시. 구현·검증됨 |
| 공식 표본과 수치형 전수는 분리 보고 | 2026-10-06 정민 지시 |
| 라벨을 채점보다 먼저 커밋하고 해시를 기록 | 기존 지시 |

## 4. 결정 전까지 코드가 하는 일

- 행별 분류와 **건수**만 낸다. `bucket_counts`·`value_match_counts`·`source_match_counts`.
- 비율·정확도·종합 점수는 내지 않고 `metrics_blocked_reason`에 이유를 적는다.
- 미정 조합은 `unresolved`로 남기고 행별 이유를 적는다. 어느 지표에도 넣지 않는다.

D1~D5가 정해지면 **그때 산식을 구현하고 테스트를 추가한다.** 지금 추정 구현을 넣어
두지 않았다.
