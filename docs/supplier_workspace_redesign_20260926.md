# 공급업체 실사 작업 화면 재설계

2026-09-26 · PR #65 (`codex/ui-guided-workspace`)

## 변경 배경

PR #65는 9월 12일 작성된 미병합 초안이었다. 당시 자동 검사는 통과했지만 실자료 AI/OCR 재실행·사용성 평가·외부 서비스 운영은 검증하지 않았다. 9월 18일 상담 피드백의 사용자 여정을 반영하여, 첫 화면과 작업 탐색·결과 목록·근거 대조 화면을 다시 구성했다. 최신 main의 D1 및 HMC 응답 정합성 수정도 병합했다.

## 제품의 중심

자동차 공급업체 담당자가 **증빙 수집 → 응답 초안 확인 → 원문·기간·범위 대조 → 담당자 보완 → 검토용 파일 준비**를 수행하는 작업 공간이다. 원청·재단은 구매 후보이며, 구매자용 관리 대시보드나 확인되지 않은 절감률·가격을 사용자 화면에 넣지 않는다.

- 홈: 새 작업과 저장한 작업, 응답과 증빙 비교 예시. 짙은 초록색 탐색 메뉴, 밝은 작업 영역.
- 자료 보관함: 기존 업로드와 자료 종류 구분을 유지. 분석 시 AI 서비스에 문서 내용이 전달됨을 안내. 고객사로 자동 전송하지 않는다.
- 답변 검토: 전체 문항·확인 필요·자료 필요·직접 작성 건수, 질문 검색과 필터. 점수를 제출 준비 상태로 대신 쓰지 않는다.
- 문항 상세: 응답 초안, 직접 작성한 값, 연결된 원문, 기간·사업장 범위, 보완할 자료와 메모. 계산에 쓰이지 않은 보완 대상 근거는 별도로 표시한다.
- 응답서: Excel/PDF 상태 라벨과 확인할 항목 수가 화면과 일치한다. 원래 엔진 판정은 감사 JSON에 보존하고, 검토용 출력에서만 보수적인 상태를 적용한다.

현대차 양식은 공개 행동규범 기반 **참고양식**, RBA는 **자가점검 참고양식**, SAQ는 **5.0 기반 매핑 시제품**으로 표기한다. 고객사의 최신 공식 질문지를 임의로 처리하거나 공식 포털에 제출하는 기능을 의미하지 않는다.

## 표시 신뢰성

- `scope_unconfirmed`, `not_comparable`, `mismatch`를 구별한다. 예시의 92%와 29.3%는 기간·사업장·분모가 확인되지 않았으므로 불일치 확정으로 표현하지 않는다.
- 연도 추정, 부분 기간, 표 읽기 미확정, 독립 근거 부족을 화면과 출력에 보존한다.
- 저장한 작업도 현재 표시 규칙으로 다시 표현하며, 이전 버전의 표 확인 경고를 유지한다.
- AI 초안의 인용 번호와 출처 목록, 값 산정에 쓰이지 않은 참고 자료를 구분한다.
- 메모 저장은 검증 상태를 변경하지 않는다. 입력이 바뀐 과거 결과는 다운로드를 막고, 재분석 후 이전 메모는 재확인 대상으로 남긴다.

## 확인한 범위

- Python 전체 검사: **1,604 통과 / 12 건너뜀**. 건너뛴 검사는 비공개 실보고서 파일이 필요한 기존 검사다.
- 웹 서버·공통 출력 관련 검사: **37 통과**. 신규 검사는 독립 근거 없음, 부분값, 추정 연도, 미확정 표, 범위 미확인, 정상 연결의 UI/Excel/PDF 상태 및 원 판정 보존을 대조한다.
- 브라우저 검사: **4 통과**. 설명 구분, 예시 대조·메모·복원·Excel 받기, 업로드·자료 종류·손상 파일, 375px/320px 및 키보드 흐름.
- TypeScript·프로덕션 빌드·서식 검사 통과. 예시 PDF 2쪽을 렌더링해 읽힘과 상태 표시를 확인했다.

검증 중 외부 AI 호출은 하지 않았다. 서버 경계와 저장·출력 동작을 확인한 것이며 실제 문서 분석 정확도나 현장 시간 절감을 새로 측정한 것은 아니다.

## 남은 실증과 확장

실기업 한 곳의 허가된 자료와 실제 요구 양식으로, 사람의 검토·수정까지 포함한 시간과 답변 품질을 비교해야 한다. 공식 양식 최신성, 고객사 수용성, 구매 주체는 별도 검증 대상이다. 여러 고객사 사이의 증빙 재사용, 문서 유효기간·공유 권한, 담당자·기한 관리, 로그인·결제·외부 배포는 이번 변경에 포함하지 않는다.

## 실행

```sh
npm --prefix frontend ci
npm --prefix frontend run build
python -m esgenie.web --port 8775
```

기본 저장 폴더는 `outputs/web_workspace`. `ESGENIE_WEB_DATA_DIR`로 분리 가능하다. `ESGENIE_FORCE_MOCK=1` 환경에서는 실제 분석을 비활성화하고 사용법 예시를 둘러볼 수 있다. 기존 Streamlit 실행 경로는 유지한다.
