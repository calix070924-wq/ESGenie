## 2. 공통 규칙 — 연결된 사실로 대조(`esgenie/report_claims.py`)

- 대조 단위: 생성 수량(`Claim`)과 근거(`Fact` 구조화 사실, `Occurrence` 청크 수량) 모두 **값·단위·역할·고용형태(집단)·날짜·사업장**을 갖는다.
- `check_quantity`의 판정(세 경로 같은 기준 `_relation_problems`):
  - 어긋남(hard): 역할·집단·날짜(겹치지 않음, 라벨로 가리키지 않은 더 넓은 기간)·사업장이 다르다. 문장이 집단을 밝혔는데 근거가 합계다(`group_unstated`). 문장이 집단 없이 쓴 값이 근거에서는 한 집단의 값이다(`group_missing`).
  - 확인 안 됨(weak): 문장은 날짜·사업장·역할을 밝혔으나 근거에 그 관계가 적혀 있지 않다.
  - 채택: 모든 관계가 맞는 근거가 있으면 그것(다른 날짜의 동률 후보가 막지 않는다). 확인 안 됨만 있는 근거는 같은 값의 어긋난 후보가 없을 때만. 인용 밖 청크는 모든 관계가 맞을 때만.
  - 고르는 순서: 인용 청크 → 원문 확인 수치 → 인용 밖 청크.
- 인용: 인용이 없으면 생성 문맥 전체가 근거 범위다. 찾지 못한 인용 번호·다른 문서 인용은 근거가 아니다. 다른 근거로 확인하면 실제 채택 출처를 감사 기록에 남긴다.
- 감사 기록(`report_body_review.json`·`ReportDoc.meta.body_reviews`):
  - 바꾼 문장: 사유 `relation_mismatch`(이전 `role_or_date_mismatch`) + `problems`(role·group·date·site …)·`cited`·`missing_citations`·`conflicts[{evidence, problems}]`.
  - 새 `action="evidence_selected"`(본문 불변): `selected_among_conflicts`(어긋난 동률 후보를 두고 고른 근거) · `citation_not_supporting`(인용이 가리키지 않은·찾지 못한 근거로 확인). `quantity`·`adopted`·`adopted_chunk`·`cited`·`missing_citations`·`rejected`.
  - 함수가 돌려주는 목록에는 넣지 않는다(본문을 바꾼·표시한 기록만). `_block_esg`·요약이 감사 기록에 함께 싣는다.
- 고용형태 사전(`_GROUP_PATTERNS`): 정규직·비정규직·기간제(=계약직)·무기계약직·파견·직접고용·간접고용·단시간·일용직. 수량을 바로 꾸미는 낱말(`정규직 40명`·`기간제 근로자는 6명`)이나 뒤 서술어(`40명은 정규직이다`)만 집단으로 읽는다. 나열 + 다른 말(`정규직·기간제·파견 포함 50명`)은 합계다. 회사명·문서 번호·정답 수치로 분기하지 않는다.

## 3. 항목별 원인·변경·대조

### A — 원문 인용이 날짜 불일치를 덮는 경로

- **원인**:
  - `check_quantity`의 청크 경로가 값·단위·역할만 보았다. 구조화 사실에서 날짜 불일치를 찾아도 원문의 같은 27명이 `Support(True)`를 돌려줬다. 인용 없는 문장은 생성 문맥 전체를 같은 방식으로 검색했다.
  - 전제 결함: 구간 날짜(`4월 13일부터 19일까지`)의 `_DateSpan.text`는 정규화된 문구라 `find(span.text)`가 실패해 그 문장의 날짜가 '없음'이 됐다(마스킹도 안 됨). 절 단위로만 날짜를 찾아 `6월 9일 교육에는, 27명이` 같은 쉼표 뒤 수량은 날짜를 잃었다.
- **변경**:
  - `chunk_occurrences`가 수량마다 `Occurrence`(역할·집단·날짜·사업장·문맥·청크 ID·출처)를 만든다. 날짜·사업장은 같은 문장의 앞 표기(없으면 같은 절 뒤 표기), 줄 전체에 없을 때만 위 **머리 줄**(문장으로 끝나지 않고 수량이 없는 줄)의 표기를 잇는다. 서술 문장의 날짜(`4월 27일 추가 교육을 예정했습니다.`)는 다른 문장의 수량에 물려주지 않는다.
  - `date_positions`: 구간 날짜의 원문 위치를 찾는다. `nearest`: 같은 문장의 앞 날짜를 쉼표 너머까지 잇는다.
  - 파일명·`(출처: …)` 꼬리표·인원번호 구간(`HN-G01~40`) 안의 숫자는 날짜·수량이 아니다.
- **수정 전 → 후**: 재검토 A 3건 중 2 실패(`[c1]`·인용 없음) → 3 통과. §8.1 날짜 오기 행 전부 보류.
- **정상 대조**: `6월 3일 참석 27명`·`6월 9일 추가 참석 3명` 세 인용 방식 모두 보존. 같은 청크의 두 날짜·두 집단 수량을 각각 판정. 다른 날짜의 같은 27명이 함께 있을 때 맞는 날짜의 근거를 채택하고 다른 날짜 후보를 `rejected`로 기록(`test_a_matching_candidate_is_chosen_over_a_same_value_candidate_of_another_date`).

### B — 인용 없는 표와 다른 출력 형식

- **원인**: `_review_table`이 인용 없는 행에 `cited_texts=None`을 넘겼고 `_sentence_review`는 None이면 수량 대조를 하지 않았다. 인용 없는 제목은 청크 없이 원장만 봤고, 요약(`annotate_summary_text`)은 수량을 대조하지 않았다. 표 행은 칸을 공백으로 이어 붙여 열 머리(정규직/기간제·단위)를 잃었고, 빈 칸을 버려 뒤 값이 앞 열로 밀렸다.
- **변경**:
  - 수량 대조를 끄는 None 경로를 없앴다. 표·제목·문장이 같은 `_Evidence`(인용 범위·인용 밖·찾지 못한 인용)를 쓴다.
  - 표: `row_claims`가 칸마다 열 머리 → 행 라벨 순으로 역할·집단, 같은 행 → 열 머리 순으로 날짜·사업장을 읽고, 칸에 단위가 없으면 열 머리 단위(`실적(명)`)를 쓴다. 틀린 칸만 `[확인 보류]`로 바꾸고 빈 칸·옆 값·비고는 제자리에 둔다(`_table_cells`).
  - 생성 경로가 원장·원문 확인 수치로 만든 표는 `GenerationResult.system_tables`(표 원문)로 식별해 그대로 둔다. 같은 제목·열 이름의 LLM 표는 대조한다.
  - 요약: 전 영역 원장·원문 확인 수치·생성 문맥 청크와 요약 생성 입력값(K-ESG·증빙 연결 커버리지 %, ISSB 누락 건)으로 대조한다. 단위 없는 점수는 표시하지 않는다.

- **실제 소비 경로**: 본문·제목·표·요약에 오답을 넣고 `_block_exec_summary`·`_block_esg` → `ReportDoc.to_markdown()`·`export_report_pdf` 결과를 대조(`test_wrong_claims_in_body_heading_table_and_summary_do_not_reach_markdown_or_pdf`), 실제 BM 경로 주입(§6 RV).

### C — 해당 사업장에 적용되는 FY 정의가 없으면 보류(`esgenie/ssot/ocr_router.py`)

- **원인**: `_fiscal_definitions`의 `[적용 정의] or found`. 적용 정의가 없으면 전체 정의로 되돌아가 부산 제2공장의 정의가 김해 제1공장의 0을 CONFIRMED(달력 연도)·REJECTED(4월 시작)로 정했다.
- **변경**:
  - 정의는 사업장이 적히지 않은 공통 정의이거나 대조 사업장을 적은 정의일 때만 적용한다.
  - 적용 정의가 없으면 `_FiscalConflict(cause="fiscal_definition_not_applicable")` → SOURCE_ONLY. 사유: `원문의 회계연도(FY) 정의는 다른 사업장에만 적용되어 김해 제1공장에 적용되는 FY 구간을 원문에서 확인할 수 없어 …`(요청 사업장명). 정의 원문은 `scope_spans`의 `fiscal_definition` 행.

## 9. 남은 한계·미검증

- **사업장 미기록 근거**: 근거에 사업장이 기록되지 않은 값(BM 09 교육 집계 — OCR 경계 사업장 없음)에 생성 문장이 다른 사업장을 붙이면, 제품은 반박할 근거가 없어 보존한다(RVS 관찰: `양산 제2공장 … 46명`). 출력 검사기는 이를 MD·PDF 모두 실패로 검출한다. 근거에 사업장이 있으면(원장 값·사업장 라벨) 제품도 보류한다. 같은 이유로 근거에 날짜가 없고 어긋난 후보도 없는 값은 문장의 날짜를 반박하지 못한다.
- **집단 판독 범위**: 고용형태 사전만 다룬다(성별·직급 등은 집단으로 대조하지 않음). 수량을 바로 꾸미지 않는 표현(`정규직의 경우 … 40명`, `각각`)은 집단을 정하지 못해 보수적으로 보류될 수 있다. 문장 단위 보류라 한 문장의 맞는 값도 함께 바뀌고, 확인된 값은 보류 문구에 남긴다.
