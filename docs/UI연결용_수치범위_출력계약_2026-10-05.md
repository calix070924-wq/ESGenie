## 1. 확정 상태 표시 계약

| 상태 | 원장(`resolved_facts[code]`) | 답변(`Answer`) | UI에 보일 것 | 하지 말 것 |
|---|---|---|---|---|
| CONFIRMED | 값 유지, `scope_source_only` 없음 | 기존 판정(`compared` 등) | 값 + 원문 범위(`boundary_label`) | 확인된 범위(`boundary_label`)보다 넓게 표기(연간·전사) |

| UNRESOLVED·값 없음 | 대표값 아님 | 증빙 대기/데이터부족 | 무엇을 확인하지 못했는지(확인 목록) | 명시적 0으로 채우기 |

`SOURCE_ONLY` 사유(`cause`)와 사람이 읽는 문구(`scope_notes`의 출처 `ocr_router._ZERO_KEPT_CAUSES`):

| cause | 뜻 |
|---|---|
| `period_not_stated` | 원문에 기간 표기가 없음 |
| `report_year_only` | 요청이 보고 연도뿐(원문은 그해 월·기준일·연도 표기) |

### 보고서 본문(LLM) — 0b770df

**바꾼 문구.** 생성 문장·제목·표 행·요약을 원장·원문 확인 수치·인용 근거와 값·단위·참여 역할(대상·참석·미참석)·날짜로 대조한다. 확인된 오류는 그 자리에서 아래 문구로 바뀐다.

- `[확인 보류] 생성 문장의 수치(…)는 … 이 문장을 본문에 싣지 않았습니다.` 뒤에 `같은 문장에서 확인된 값: …`과 `원문 확인 값: 라벨 N명(날짜) — 출처; …`이 이어진다.
- `[범위 미확정] {지표} {값}는 원문 범위(…)로만 확인된 참고값이며, 요청 기간·사업장의 확정 실적인지 확인하지 못했습니다(사유).`
  - 표에서는 칸에 `[범위 미확정: 원문 범위로만 확인된 참고값]`이 붙고, 머리글 `확정 실적`은 `실적`으로 바뀐다.
  - 제목에서는 `(범위 미확정 참고값 — 요청 범위의 확정 실적 아님)`이 붙는다.
- `[범위 주의] {지표} {값}의 원장 범위는 …이며 전체·연간·합산 값이 아닙니다.`

**`[검토: …]` 표시.** 판단이 갈리는 경우에만 붙는다: 목표 문장, 값 없이 범위 낱말만, 단위 없는 숫자, 지표를 특정하지 못한 값.

**결정적 표.** `### 원문 확인 수치(K-ESG 코드 없음)`(항목·값·기간·출처)는 LLM을 거치지 않는다. 교육 날짜별 인원·공정 스크랩 합계 등이 여기 실린다.

**감사 기록.** `report_body_review.json`과 `ReportDoc.meta.body_reviews`에 들어 있다. 행마다:

- `block`·`area`·`reason`(orphan_number / role_or_date_mismatch / source_only_stated / scope_widened)·`action`(replaced / marked)
- `model_text`(모델 원문)·`output`(바꾼 문구)·`numbers`·`quantities`·`related`·`conflicts`·`code`

**UI 표시 원칙.** 바꾼 문구와 표시를 지우거나 숨기지 않는다. 모델 원문은 감사 보기에서만 보인다.

## 5. UI에서 확인할 남은 연결 항목

1. `comparison_reason` 전문을 E-6-2처럼 긴 경우에도 자르지 않고 보이기(목록에는 요지, 상세에는 전문). 회사 답변 92%와 증빙 29.3%를 나란히 두고 `traced_node_id` 노드로 08 원문 보기 연결.
2. `scope_source_only`를 일반 '자가신고'와 구별되는 표시로(같은 행에 범위 확인 필요 + 사유). '대조 완료' 문구를 쓰지 않기.
3. `boundary_label`을 값 옆에 함께 표시. `display_value`의 `(2026년)`은 보고 연도라 범위로 오해하지 않게.
4. `label_check` 정정 노드(09 대상·13 고유 인원·08 합계)는 원문 라벨로 보이고, 감사 보기에서 모델 라벨을 함께.

6. 보고서 본문을 노출할 경우 다음을 유지한다:
   - `[확인 보류]`·`[범위 미확정]`·`[범위 주의]` 문구와 `[검토: …]` 표시를 바꾸거나 숨기지 않는다.
