### 숫자 추출

기존 정규식의 1~3자리 시작 제한을 제거했다. 공용 `numeric_tokens.py`에서 전체 후보를 먼저 읽고 표기 형식을 검증하므로 `9,99`, `1.2.3`, `--100`, `- 100`에서 일부 숫자만 정상값으로 나오지 않는다. D1과 SSOT는 같은 숫자 문법을 공유하며 각 경로의 기존 단위 목록을 유지한다. D5의 공용 패턴 사용도 회귀 검사했다.

- 0, 소수, 999/1000 경계, 9999/9,999, 12345.67/12,345.67, 1000000/1,000,000, 단위 앞 공백 유무의 값·단위·주장 수·D1 판정이 동일하다.
- `+100`을 지원하며 `-100`/`−100`의 부호를 보존한다. 현재 지원하는 실적 검증에서 음수는 `invalid_number`로 사람 검토에 남긴다.
- 지수 표기, 정수부 없는 `.5`, 비정상 쉼표, 분리된/중복된 부호는 이번 파서의 지원 범위 밖이다. 지원 단위가 붙으면 미검증 사유가 남는다.
- `%p`를 `%`보다 먼저 전체 토큰으로 읽는다. `%p`와 `%`는 서로 환산하거나 일치시키지 않는다. `만 tCO2eq` 배수와 Scope3/RE100/IFRS S2/연도·식별자 보호를 유지했다.

### 주장과 지표 연결

문장 내 모든 지표 증빙에서 수치 오차가 가장 작은 값을 찾던 교차 비교를 없앴다. 절 경계, 지표 표현, 숫자와 표현의 위치를 먼저 사용하고 해당 코드의 확정값만 비교한다. 기존 25자 근접 한도와 토픽 인덱스를 유지한다.

정상/역순 다지표, 문장 분리, 쉼표·접속사 구분, `31%인 재생에너지…`, `31%는 재생에너지…`를 검사했다. 두 지표와 두 숫자를 연결할 수 없는 나열은 `ambiguous_topic`으로 남긴다. 목표 판정은 절 안에서 수행하므로 목표 절 옆 실적까지 제외하지 않는다.

`ResolvedFact`의 명시적 `None`은 후보 재선택으로 되살리지 않는다. 구버전의 메타데이터 부재는 기존 대표 선택 규칙으로 처리한다. 단위 비교 전에 대표값을 정하고, 단위가 맞는 부분값·오염값으로 재선택하지 않는다. 248.5/61.2/999.0 기존 회귀, 단위 환산, Scope 1+2 합산을 유지했다.

## 미검증 상태 정책과 호환성

기존 `AxisScore.evaluation` 딕셔너리를 활용해 다음을 기록한다.

```text
status: complete | partial | unavailable | not_applicable
compared_claims, unverified_claims, excluded_claims
reasons: {no_evidence | unit_mismatch | ambiguous_topic | invalid_number: 개수}
claims: 원문, start/end, code, 주장값/단위, 증빙값/단위/연도,
        근거 ID/파일, 환산값, 오차, 상태, 판정 이유
```

위치의 끝은 exclusive이며 실제 입력 문자열 기준이다. 목표 수치는 `excluded/target`, 실적 수치가 없는 경우는 `not_applicable`이다. 음수 원문과 값은 숨기지 않는다. 0 증빙도 비교하며 0에 대한 비영(非零) 주장의 무한 상대오차는 JSON에서 null과 별도 플래그로 표현한다.

- 모든 비교 대상 주장이 미검증이면 D1 `abstain=True`, 내부 score=0. 다른 유효 축의 가중치는 기존대로 재정규화한다. 전 축 기권이면 종합 점수는 null이다.
- 일부 비교가 있으면 D1은 기권하지 않고 계산한 점수를 유지한다. `evaluation.status=partial`, 종합 `evaluation_complete=False`로 사람 검토가 필요하다.
- L4는 가장 위험한 문장의 점수 정책을 유지하면서 모든 문장의 D1 범위를 `aggregate.numeric_evaluation`에 합친다. 낮은 위험 문장의 미검증도 최종 상태에서 사라지지 않는다.
- LLM 설명은 독립 증빙을 추가하지 못한다. 보정/캐시 재생에서도 범위를 복사하며, 실제 증빙 비교에서 나온 D1 불일치 점수를 설명만으로 낮추지 않는다.
- `ABSTAIN_ENABLED`, `ABSTAIN_UNIT_MISMATCH` 기본값은 True다. 과거 환경변수 이름은 읽기 호환용으로 남겼지만, False도 D1 미검증 표시·기권을 비활성화하지 않는다. 두 플래그의 네 조합에서 동일한 범위 보존을 검사했다. 과거 `with_abstain_ignored`는 분류 실험의 해석만 바꾸며 새 평가 범위는 유지한다.
- 위험 가중치 D1=.4, D2=.25, D3=.25, D5=.1 및 D1_THRESHOLD=.15는 변경하지 않았다. SSOT의 기존 ±2% 허용오차와 실제 불일치 점수 산식도 유지했다.
- 구버전 `AxisScore`의 evaluation 누락은 `{}`로 읽힌다. 과거 결과에 주장별 검증 정보를 소급해서 만들어 주지는 않는다. `DataPoint.d1_evaluation`도 기본 `{}`이며, 새 전부 미검증 D1 위험도는 null이다. Excel은 과거 자료의 범위 미기록을 별도로 표시한다.

### 기존 D1 평가

`batch_c_truth_holdout.json` 24건을 기존 지표·설정으로 비교했다. 수정 전후 TP=12, FP=0, FN=0, TN=12, P/R/F1=1.0이다. 기존 OFF/OFF 설정으로도 같은 결과다. 기존 `scripts/d1_truth_eval.py` 자체도 실행했고 [실행 출력](validation/d1-20260914/existing-d1-eval.txt)을 남겼다. 이 자료는 이미 알려진 회귀 자료이며 새로운 일반화 성능으로 주장하지 않는다. 수치 임계값을 맞추는 사후 조정은 수행하지 않았다.

저장된 현대모비스 다지표 문장(`test_d1_topic_match.LIVE_SENTENCE`)의 기존 10개 추출과 D1=0을 유지했다. 원부자재·재생 원부자재·Scope3 등 기존 오귀속 방지 회귀도 통과했다. 이번 실행한 회귀 범위에서는 새 오탐이 없었다.

### 원문 대조 범위

현대모비스 2025 지속가능성보고서 PDF와 원본 폴더의 저장된 2026-07-30 OCR 결과를 읽기 전용으로 대조했다. 기존 추출 제공자는 OpenAI, 모델은 `gpt-4.1-mini`로 기록돼 있다. **이번에는 API를 다시 호출하지 않았다.** [재현용 실제 발췌](../data/d1_validation/real_excerpt.json)에 PDF/캐시 SHA-256, 원문, 값, 단위, 연도, 범위, 페이지를 기록했다. 코드와 페이지는 원문 확인 후 수동 연결했으며 자동 추출이 이를 복구했다는 주장으로 사용하지 않는다.

- PDF 인쇄 70쪽(0 기준 69): 2024년 국내·해외 합계 폐기물 발생량 **72,463 ton**. 저장 추출 → 그래프 → 확정 원장 → 화면 → 감사 JSON/Excel에서 **72,463톤 / 2024 / 같은 근거 페이지**를 확인했다. 월간 수치가 아닌 연간 총량이다.
- 같은 표의 국내(별도) 재활용률 **92.9% / 2024**는 67쪽 서술과도 일치한다. 다만 기존 선택기가 `폐기물 매립 제로화(재활용률)` 라벨을 component로 분류해 원장 확정을 하지 않는다. 이번 D1은 이를 0점 정상 일치로 되살리지 않고 **no_evidence**로 보류한다. 실제 문서 대조에서 드러난 기존 선택 한계로 남겼다.

추가로 확인한 기존 후속 항목:
