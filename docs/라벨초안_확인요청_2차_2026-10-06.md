# 라벨 초안 — 확인 대기 7문항의 **2차 근거 보완** (2026-10-06)

**비공개.** B의 독립 라벨 제출 전에는 공개 PR·B 패키지에 넣지 않는다.

1차 표(`docs/라벨초안_확인요청_2026-10-06.md`)를 **반복하지 않는다.** 그 표를 읽은
뒤에 이 문서를 본다. 여기에는 **원본을 다시 읽어 새로 확인한 근거**와 **남은 선택지**만
적는다. 초안 값은 승인 전이므로 **고치지 않았다.**

## 0. 7문항 전체에 새로 걸린 범위 한계 (원본에서 새로 확인)

| 문서 | 원문 | 뜻 |
|---|---|---|
| `06…#1` 적용 범위 | "김해 제1공장·**양산 제2공장**, 각 사업장의 근무 인원" | 규정은 두 공장에 걸린다 |
| `10…#1` 적용 범위 | "김해 제1공장·양산 제2공장의 임직원과 현장 근무 인원" | 같음 |
| `11…#1` 적용 범위 | "**두 공장**의 업무 문서와 임직원·거래처 정보" | 같음 |
| `01…#1` 이번 묶음의 범위 | "운영 수치와 교육 기록은 **김해 제1공장을 중심으로** 정리했습니다. 해당 공장 인원 **50명**" | 운영 기록은 한 공장만 |
| `01…#1` 인원 | 전체 **73명** (제1공장 50 + 제2공장 23) | 운영 기록이 덮는 인원은 50/73 |

이행되는가"의 간격이 문서 범위로 확정돼 있다. 이 한계는 7문항뿐 아니라 B·E 이행 문항과
C 수치 문항에 공통으로 걸린다.

## 1. 복합 문항 — 요건별로 나눈 결과 (원칙 ②)

1차 표는 "요건 일부 충족"까지만 적었다. 요건별 입증/미확인을 **나눠** 다시 적는다.

### 1.1 `RBA-E-2` — 초안 `answer`/`아니오`

문항 원문: "경영시스템 이행 책임 임원·담당자 **지정**, 경영진 **정기 검토**."

| 요건 | 상태 | 새로 확인한 근거 |
|---|---|---|
| 책임자 지정 | **입증** | `06…#1` 관리 책임 = 생산·안전 담당자 / 경영지원 담당자, 승인 대표이사 2026-01-02. `01…#1` 업무분장 4행(담당별 확인 자료 지정) |
| 경영진 **검토 행위** | **부분 입증 (1차 표에 없던 근거)** | `01…#1` 업무분장 "대표이사 — **규정 승인 및 최종 회신 내용 확인**" / `06…#1` 제4조 "작성한 답변과 근거를 **대표이사가 확인한 뒤** 회신한다" |
| 검토의 **정기성(주기)** | **미확인** | 두 근거 모두 **건별 확인**이다. 주기를 정한 문구가 세트에 없다 |

**초안을 그대로 둘 수 없는 이유:** 초안은 `아니오`로 확정했다. 그런데 새 근거로 보면
경영진 검토 행위 자체는 문서화돼 있고, 없는 것은 **주기**다. 주기 문구가 없다는 사실은
정기 검토를 하지 않았다는 사실이 아니다(원칙 ①). `아니오`는 "하지 않는다"는 판정이므로
이 자료로는 받칠 수 없다.

| 남은 선택지 | 내용 |
|---|---|
| **(가)** | `hold` / `needs_human_text` — 지정은 입증, 정기성은 미확인. **A의 의견은 이쪽이다** |
| (나) | `answer` / `예` — 대표이사 확인 체계가 있으면 충족으로 본다 |
| (다) | `answer` / `아니오` 유지 — "정기 검토 주기 미명시"를 미충족으로 본다. 원칙 ①과 충돌하므로 그 뜻을 명시해 주셔야 적용한다 |

### 1.2 `RBA-E-3` — 초안 `answer`/`예`

문항 원문: "법규·규정·고객 요구사항 식별·모니터링·이해 **프로세스**."

**1차 표에서 "E-2와 방향이 반대"라고 적었는데, 원문을 다시 보면 그 차이에 근거가
있다(원칙 ③).** 문항이 요구하는 것이 **프로세스**이므로 절차 문서가 요건에 직접
대응한다. E-2는 "정기 검토"라는 **행위**를 묻는다 — 문서로 대체되지 않는다.

| 요건 | 상태 | 근거 |
|---|---|---|
| 고객 요구사항 식별·이해 프로세스 | **입증** | `06…#1` 제4조 — 고객사 질문의 기간·사업장·요구 증빙 확인 → 부서 자료 요청 → 미확인 사유 기재 → 대표이사 확인 후 회신 |
| **법규** 식별·모니터링 프로세스 | **미확인 (새로 확인)** | 세트의 어느 규정에도 법규 식별·모니터링 절차가 없다. `06…#1` 제5조는 법규를 언급하지만 "규정 보유만으로 **법규 준수가 입증되는 것은 아니다**"라는 유보 문장이고 절차가 아니다. `11…#1` 제4조의 "향후 인증 준비 검토"는 법규가 아니라 인증이다 |

| 남은 선택지 | 내용 |
|---|---|
| **(가)** | `hold` / `needs_human_text` — 두 요건 중 하나만 입증. E-2를 (가)로 정하면 기준이 일관된다. **A의 의견은 이쪽이다** |
| (나) | `answer` / `예` 유지 — 고객 요구사항 프로세스가 문항의 핵심이라고 본다 |

→ **E-2와 E-3을 같은 칸에 넣는 기준은 "요건이 하나라도 미확인이면 `hold`"다.** 두
문항의 방향이 반대였던 것은 기준 부재 때문이고, 원문 차이(프로세스 vs 행위)는 기준이
아니라 **무엇이 입증 가능한가**의 차이였다.

### 1.3 `RBA-E-11` — 초안 `answer`/`예` · 영향 범위가 **줄었다**

문항 원문: "법규 준수·요건 적합 **입증을 위한 문서·기록 생성·유지**(프라이버시 보호
포함)."

**1차 표는 이 행을 "규정 문서만으로 `예`를 줄 수 있는가"에 걸어 두었다. 원문을 다시
보면 그 결정에 덜 의존한다(새 발견).** 문항이 묻는 것은 기록의 **생성·유지**이고, 이번
세트 자체가 그 직접 증거다.

| 요건 | 상태 | 근거 (규정이 아닌 **실물 기록**) |
|---|---|---|
| 기록 생성·유지 | **입증** | `04…#1` 위탁 처리 명세(처리일별, 확인일 2026-05-04) · `08…#1` 스크랩 대장(주별, 월말 대조) · `09…#1` 교육 출석 기록 · `12…#1` 근로시간 기록 — 모두 작성자·확인자·작성일이 적힌 실제 기록이다 |
| 프라이버시 보호 | **입증** | `11…#1` 제2조 "근태·교육 자료에는 **익명 인원번호를 우선 사용**하고 주민등록번호·실명 서명 등 불필요한 개인정보는 포함하지 않는다" + `09`·`12`가 실제로 `HN-G**`만 쓴다(규정과 운영이 일치) |
| 보관·백업 체계 | **입증(규정)** | `11…#1` 제1·3조, `06…#1` 제5조 원본·수정이력 구분 보관 |
| 보관 기간·점검 주기 | **미확인** | 세트에 보관 연한이나 기록 점검 주기 문구가 없다 |

| 남은 선택지 | 내용 |
|---|---|
| **(가)** | `answer` / `예` 유지 — 규정뿐 아니라 **실물 기록 4건**이 생성·유지를 입증한다. **A의 의견은 이쪽이다** |
| (나) | `hold` / `needs_human_text` — 보관 기간·점검 주기 미확인을 요건 미충족으로 본다 |

**연동이 끊어진 부분:** 1차 표는 "`E-11` 기준을 바꾸면 `E-8`도 함께 바뀐다"고 적었다.
이제 **그렇지 않다.** `E-11`에는 운영 기록이 있고 `E-8`에는 없다.

### 1.4 `RBA-E-8` — 1차에서 "쟁점 없음 쪽"에 두었으나 **독립 쟁점으로 올린다**

문항 원문: "근로자·대표·**이해관계자**와 양방향 소통, 보복 없는 고충·피드백 환경, 구제

## 2. 폐기물 수치 2문항 — 기간·대상·분모를 원본으로 확인 (원칙 ④)

**계약 문서의 기대값을 보지 않았고 복사하지 않았다.** 아래는 전부 `04`·`06`·`08`
원문이다.

### 2.1 원본이 **이미 확정해 주는 것** (1차 표에서 "쟁점"으로 적었던 분모)

| 항목 | `04…#1` 원문 | 판단 |
|---|---|---|
| 기간 | "2026-04-01 ~ 2026-04-30" | 한 달 |
| 대상 | 문서 범위 "이 기간에 **공장 밖으로 위탁 처리한** 폐기물의 인계·처리 중량. 공정 안에서 재투입한 스크랩은 **제외**합니다" | 위탁 기준이 문서 범위로 명시 |
| 분자·분모 | 집계 기준 "분자: 외부 위탁 폐기물 중 재활용 처리 중량. 분모: 재활용·소각·매립을 합한 전체 외부 위탁 처리 중량. 내부 재투입 11,500 kg는 이 집계에 **포함하지 않습니다**" | 분모 = 18,400 kg로 명시 |
| 계산식 | "5,400 ÷ 18,400 × 100 = 29.3478…% → 소수 첫째 자리 **29.3%**" | 반올림 자리까지 원본 표기 |
| 중복 | `08…#1` "외부 반출 1,000 kg는 … `HW-WST-202604`에 **한 번** 포함되어 있다. 두 대장의 값을 더해 중복 집계하지 않는다" | 18,400에 1,000이 이미 포함 |
| 합산 금지 | `06…#1` 제2조 "내부 스크랩 재투입량과 외부 위탁 폐기물 재활용량을 **서로 다른 대장으로 관리**하고, 비율에는 계산식과 기간·사업장을 함께 적는다" | 두 지표를 합친 비율을 만들 근거가 원본에 없다 |

→ **"발생량 기준으로 보면 분모가 달라진다"는 1차 표의 쟁점은 원본 쪽에서 좁혀졌다.**
발생 기준을 쓰려면 18,400 + 11,500 = 29,900 kg, 재활용은 (5,400 + 11,500) ÷ 29,900 =
56.5%가 되는데, **그렇게 묶지 말라는 규정 문구(`06` 제2조)가 원본에 있다.** `08`의
92.0%는 분모 12,500 kg(공정 스크랩 발생)인 **또 다른 지표**다.

### 2.2 원본으로도 **남는 것** — 06 제1조는 여기에 쓸 수 없다

`06…#1` 제1조의 "일부 월 값을 실제 연간 실적으로 표시하지 않는다"는 **에너지·용수
기록 조항**이다. 폐기물에 적용하면 원문을 넘긴다 — 폐기물은 제2조이고, 제2조가
요구하는 것은 **기간·사업장 병기**이며 `04`가 그것을 지켰다.

그래서 남는 쟁점은 분모가 아니라 **문항의 기간·사업장**이다.

| 남은 쟁점 | 내용 |
|---|---|
| 기간 | 문항(`[C-4·수치] 폐기물 배출량`, `폐기물 재활용(순환이용)률`)은 기간을 한정하지 않는다. 자료는 2026-04 한 달뿐이다 |
| 사업장 | 자료는 김해 제1공장만. 규정 적용 범위는 두 공장(§0) |

| 남은 선택지 | 두 행에 함께 적용 |
|---|---|
| **(가)** | `answer` 유지 — `18.4` 톤 / `29.3` % · `boundary_note`에 "2026-04 · 김해 제1공장 · 외부 위탁 기준 · 부분값"을 적는다. kg→톤은 ÷1000의 정확 환산이고 가정이 들어가지 않는다. **A의 의견은 이쪽이다** |
| (나) | `hold` / `scope_unconfirmed` — 기간 무지정 문항에 한 달·한 공장 값을 답으로 두지 않는다 |
| (다) | 발생량 기준(`29,900 kg` / `56.5%`) — **`06` 제2조와 충돌한다.** 쓰려면 그 충돌을 감수한다는 지시가 필요하다 |

**독립성:** 이 두 문항은 A가 ESGenie 응답을 미리 본 문항이다(1차 표 §0). 위 근거는
원본 재확인으로 얻었지만 **독립 산출이라고 주장하지 않는다.**

## 3. 에너지·온실가스 2문항 — 부족한 것이 서로 다르다 (원칙 ⑤)

**사유를 통일하지 않는다.** 요청 측정량·기초자료·환산계수·기간을 칸으로 갈라 보면 두
문항의 결손 위치가 다르다.

| | `RBA-C-8-E-4-1` 에너지 사용량 (`TJ`) | `RBA-C-8-E-3-1` 온실가스 배출량 (`tCO2eq`, Scope 1+2) |
|---|---|---|
| **요청 측정량** | 에너지량 | 배출량 |
| **기초자료** | **있다** — `02…#1` 142,560 kWh, `03…#1` 8,420 m³ (요청 측정량과 **같은 계열**의 물리량) | **일부만** — 전기·가스 사용량뿐. Scope 1+2 전체(자가 연소·냉매 등)를 덮는지 확인할 자료가 없다 |
| **산정 결과물** | 없음 | **없다고 원본이 직접 적는다** — `01…#1` "2025년 전사 연간 온실가스 산정자료는 이 묶음에 포함하지 않았습니다. 2026년 4월 고지서로 대체할 수 없습니다" |
| **환산계수** | **없다** — `03…#1` "발열량·보정계수·온실가스 배출계수는 제시하지 않으며, **연간 에너지 사용량이나 배출량 산정표를 대신하지 않습니다**" | 없다 (같은 문구) |
| **기간·사업장** | 2026-04 한 달·제1공장. `06…#1` **제1조가 "일부 월 값을 실제 연간 실적으로 표시하지 않는다"고 직접 금지**(이 조항은 에너지·용수에 걸린다) | 같음. 더해서 전사 연간 자료가 없다고 `01`이 명시 |
| **결손의 성격** | 기초자료는 있고 **요구 단위로 옮길 수 없다** | 요청 측정량의 **산정 결과물 자체가 없다** |

### 남은 선택지

| 문항 | 선택지 |
|---|---|
| `E-4-1` | **(가)** `hold`/`not_comparable` 유지 — 기초자료가 있고 환산만 막혔다. **A의 의견은 이쪽이다.** 단 `boundary_note`에 기간·사업장 한계와 `06` 제1조를 **함께** 적는다(사유가 둘이다) |
| | (나) `hold`/`scope_unconfirmed` — 환산계수보다 기간·사업장 문제를 앞세운다 |
| | (다) `hold`/`no_evidence` — **A는 반대한다.** 사용량 기초자료가 있으므로 "자료 없음"은 사실과 다르다 |
| `E-3-1` | **(가)** `hold`/`no_evidence` 유지 — `01`이 산정자료 부재를 직접 적는다. **A의 의견은 이쪽이다** |
| | (나) `hold`/`not_comparable` — 전기·가스 사용량을 기초자료로 보고 계수 부재만 본다. **A는 반대한다** — Scope 1+2 전체를 덮는지 확인할 수 없어 "계수만 있으면 환산된다"가 성립하지 않는다 |
