## 요약

지표 오매핑(정답셋 30건 중 오염 16건의 1위 원인)을 `_resolve_kesg_code`의 3중 게이트
+ 미래기간 분리 + 노드 선택 변경 + 각주 배제로 차단한다. 실측 8사례 중 **7건이 게이트로
차단/정정**되고, 1건(사례8)은 코드가 아닌 값 오류라 범위 밖으로 명시했다.

## 작업0 대비 확정된 설계 보정 (3건)

1. **단위**: 설계의 ML·㎥·m3는 kesg_items 항목 단위에 없어 실효 0 → **TJ·kg·건·‰**를
   등록(TJ가 E-4-1 핵심). 에너지 환산군 TJ↔GJ↔MWh↔kWh, 질량군 t↔kg 정의.
2. **G2**: 현재 사전 내 부분문자열 충돌은 판정을 안 뒤집음(전부 동일코드). G2의 실익은
   **신규 키 정정** — `용수재이용률→E-5-2` 추가로 용수 사용량(ton) 오매핑을 올바른
   비율 코드로 정정.
3. **사례8(자발적 이직률)**: `이직률→S-2-3`로 이미 정상 매칭. 오류는 값(6.3 vs 12.7)이라
   매칭 게이트 범위 밖 — 회귀 테스트에서 "코드 정상 부여"만 고정.

| 게이트 | 위치 | 동작 |

**매칭 실패 정책**(개편안 §4): 코드만 None, `metric_hint`는 보존(노드 폐기 아님) — 감사
추적 유지, L1은 미공시로 표기(Phase 1 v2 표가 정상 렌더).

### G4 임계값을 +2로 둔 이유 (설계 `> report_year`에서 보정)

설계는 `period > report_year`였으나, 전기요금 명세(2025-12)가 DART 공시연도(2024)보다
1년 앞서는 정상 사례를 projection으로 오분류했다(기존 ssot 테스트 3건 깨짐). 목표축
연도(2030/2035/2040)는 +2 이상이라 **+2 임계값**이 최신 증빙은 살리고 전망만 거른다.
`tests/test_ssot.py`의 waste 픽스처 period(2026, report 2024→gap2)는 승격 테스트 의도에
맞게 report_year와 정렬(2024)로 수정.

## 커버리지 트레이드오프 (개편안 §5)

오염 노드가 코드 미부여로 빠지면 **커버리지는 하락**하나(추정 47%→38~42%), 빠지는 것은
전부 오매핑·전망·각주 오파싱 노드다. "커버리지 42%(오염 포함) vs 38%(검증 통과)"를 나란히
제시하는 것이 정직한 수치 — 증빙 연결 커버리지(Phase 2)와 함께 보면 정확도는 상승한다.
하락분 원인은 위 census `--diff`의 플래그별 건수로 노드 단위 설명 가능.
