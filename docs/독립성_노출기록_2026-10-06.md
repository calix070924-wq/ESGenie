# 기대값 노출 기록과 독립 검토 인정 판단 (2026-10-06)

**이 문서는 B에게 전달하는 패키지에 넣지 않는다.** 노출된 문항이 무엇인지 적혀 있기
때문이다. 수치 자체는 이 문서에 옮겨 적지 않았다.

## 1. 왜 기록하는가

"PR 전체를 탐색하지 말라"고 안내하는 것만으로는 독립성이 확보되지 않는다. B가 이미
해당 문서를 열었을 수 있고, 그 경우 그 문항의 B 라벨은 독립 라벨이 아니다. 그래서
**노출 경로를 미리 적어 두고, 노출이 확인되면 문항 단위로 독립 검토 인정 여부를 따로
판단한다.** 전체 표본을 무효로 돌리지도, 노출을 덮지도 않는다.

## 2. 기대값이 적혀 있는 문서 (A가 확인한 범위)

| 문서 | 어떤 형태로 적혀 있는가 | 관련 문항 |
|---|---|---|
| `docs/validation/eval-scoring-20261006/README.md` §5.4 | ESGenie 기대값 2건을 교차 확인 항목으로 인용 | `RBA-C-4-E-6-2`, K-ESG 08 노드(재투입률) |
| `docs/UI연결용_수치범위_출력계약_2026-10-05.md` (main 병합본) | 수치 범위 출력 예시에 값이 들어 있다 | 위와 같음 |
| PR #71 본문·리뷰 기록 | 수치 범위 교정 과정에서 값이 언급됨 | 위와 같음 |

K-ESG 08 노드(재투입률)는 rba42 문항 ID로 직접 대응되지 않는다. rba42 표본에
포함되는지는 원본 자료 확보 후 매핑을 확인해야 안다. **확인 전까지는 노출 가능으로
취급한다.**

## 3. 검토 집합과의 겹침

| 검토 집합 | 노출 문항 포함 | 비고 |
|---|---|---|
| 공식 무작위 표본 `bm_rba42_v1` (단계별 10문항) | **없음** | 표본 10문항에 `RBA-C-4-E-6-2`가 들어가지 않았다 |
| 수치형 전수 `bm_rba42_numeric_census` (단계별 6문항) | **있음 — `RBA-C-4-E-6-2`** | 전수이므로 반드시 포함된다 |

공식 표본은 노출 문항을 피하려고 고르거나 다시 뽑은 것이 아니다. 씨값 20261006으로
뽑힌 결과가 그렇게 나왔을 뿐이며, **노출을 이유로 재추출하지 않는다.**

## 4. 노출 확인 절차 (B 라벨 제출 시 함께 받는다)

B에게 라벨과 함께 다음을 받는다. A도 같은 항목을 자기 라벨에 적는다.

1. 라벨링 전에 `docs/validation/eval-scoring-20261006/README.md`,
   `docs/UI연결용_수치범위_출력계약_2026-10-05.md`, PR #71 본문을 열었는가.
2. 열었다면 **어느 문항의 기대값을 보았는가**(문항 ID 단위).
3. ESGenie 응답(`result.json`·`exports/`)을 열었는가.

## 5. 인정 여부 판단 기준 (제안 — 정민 확인 필요)

| 상황 | 그 문항의 B 라벨 처리 |
|---|---|
| 노출 없음 | **독립 라벨로 인정** |
| 노출 있음 + A·B 라벨 일치 | **독립 일치로 세지 않는다.** 일치율 분자·분모에서 빼고 별도 표시 |
| 노출 있음 + A·B 라벨 불일치 | 불일치로 기록하되 노출 사실을 함께 적는다 |
| ESGenie 응답을 본 뒤 라벨링 | 그 문항은 **독립 검토 불인정.** 제3자 재라벨링이 필요하다 |

- 노출 문항을 **라벨에서 제외하지 않는다.** 정답 라벨 자체는 필요하다. 빼는 것은
  "독립 일치율"의 계산 대상에서다.
- 공식 표본의 일치율과 수치형 전수 결과는 **분리해서 보고한다.** 노출 문항은 전수
  집합에만 있으므로, 둘을 합치면 노출 영향이 공식 표본 수치에 섞인다.
- 노출 문항이 많아 공식 표본의 독립 인정 행이 줄어들면, **일치율을 그대로 쓰지 않고
  분모가 줄었다는 사실을 함께 적는다.** 줄어든 분모를 숨기고 비율만 내지 않는다.

## 6. 현재 상태

| 항목 | 상태 |
|---|---|
| B의 열람 여부 | **확인되지 않음** — B에게 묻지 않았다(§4를 라벨 제출 시 함께 받는다) |
| A의 열람 여부 | **A는 두 문서를 모두 열었다.** 따라서 `RBA-C-4-E-6-2`와 08 노드에 대해 A는 독립 라벨러가 아니다 |
| 조치 | 해당 두 문항은 **A가 단독으로 라벨을 확정하지 않는다.** B 또는 제3자의 라벨을 기준으로 삼고, A 라벨은 참고로만 쓴다 |
| 인정 기준 확정 | **미확정** — §5는 제안이다 |

A가 이미 열었다는 점은 피할 수 없다(PR #71 작업 과정에서 봤다). 그래서 숨기지 않고
위와 같이 적는다. 이 사실은 `docs/validation/eval-scoring-20261006/README.md`에도
반영한다.
