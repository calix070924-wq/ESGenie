## D3 제품 동작 변경

근거 청크 없음, 빈 인덱스, 검색 결과 없음은 `abstain=True`, `abstain_reason=no_evidence`다. 기권 축은 가중평균에서 제외하고 유효 가중치를 재정규화한다. 평가 축·기권 축·유효 가중치·완료 여부를 JSON에 보존하며 화면과 보고서에 부분 평가를 표시한다. 전 축 기권은 점수 `null`과 평가불가로 표시한다.

예를 들어 D1=1, D2=0, D3 기권, D5=0이면 유효 가중치 0.75, 종합 점수는 `0.4 / 0.75 = 0.5333`이다. 내부 기권값 0을 위험 없음으로 계산하지 않는다. D1/D2/D5 검출 기준과 기존 위험도 임계값은 바꾸지 않았다.

검색 게이트가 생성을 보류하는 조기 종료도 같은 계약을 사용한다. 첫 실제 실행에서 이 경로의 `risk_vector=None`과 기존 위험도 100을 발견해 수정했다. 이제 평가불가와 사람 검토 필요를 반환한다. 불완전 평가는 자동 수렴으로 처리하지 않는다. 영역 본문과 항목별 위험도 표를 모두 확인했다.

기권 사유 집계에서는 한 사례의 D1과 D3에 같은 사유가 있어도 사례를 중복 집계하지 않는다. 기권 정밀도는 계산 정밀도를 보존하고 표시 시 반올림한다.
