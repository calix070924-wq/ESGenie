**설계(`작업0b` §5)의 3축으로는 안 풀리는 코드가 있다.** 4번째 축 **세부 분해**를 추가해야 한다.

## 5. period 불신 근거 — 동일 hint 중복

같은 (코드, hint)에 값이 여러 개인 조합이 **42건**이다. 최다 사례:

| 코드 | 중복 | 값 | hint |
|---|---|---|---|
| E-4-1 | ×8 | 4,654 / 390 / 74 / 45 / 0 ×4 | `전력구매계약(On-site PPA)` |
| E-4-1 | ×6 | 721,222 / 708,511 / 706,763 / 151 / 151 / 148 | `구매한 전력량` |
| E-6-1 | ×6 | 51,473 / 45,491 / 41,229 / 16,490 / 13,609 / 13,072 | `일반 폐기물 합계` |
| E-6-1 | ×3 | 19,352 / 17,694 / 17,129 | `폐기물 처리량(매립, 소각 등) 합계` |

hint가 완전히 같은데 값이 다르다 — 원문 표의 연도 열이 한 period로 뭉개진 것이다.
E-4-1의 ×8·×6은 여기에 **단위 열(MWh/TJ)까지 섞여 있다**.

**함의**: period로는 이 중복을 가를 수 없다. 선택 규칙에서 연도를 최후 tie-breaker로
강등한 근거다. 표 파싱 교정은 L0 소관이라 이번 범위 밖(설계 §6-4).
