# 라벨 초안 — 사람 확인이 필요한 행 (2026-10-06)

`data/eval/labels_draft/`의 AI 초안 중 **AI가 단독으로 정하면 안 되는 행**만 모았다.
각 행에 원본 파일·페이지와 판단이 갈리는 이유를 함께 적었다. **쟁점이 있다는 사실을
숨기고 한쪽으로 확정하지 않는다.**

전체 32행(공식 표본 20 + 수치형 전수 12) 중 **확인요청 7문항 / 16행**(두 단계 동일).
문항 `RBA-C-8-E-3-1`은 두 집합에 모두 들어 있어 4행이다. CSV의 `note`가 `확인요청`으로
시작하는 행과 아래 목록이 일치한다(기계로 대조 확인).

문항이 두 가지를 함께 요구하는데 증빙이 한쪽만 덮는다. **부분 충족을 `예`로 볼지
`아니오`로 볼지, 아니면 `hold`로 둘지가 쟁점이다.**

## 2. 측정 범위 — 무엇을 분모로 보는가

### 2.1 `RBA-C-4-E-6-1` 폐기물 배출량 — 초안 `answer` / `18.4` 톤

| 항목 | 내용 |
|---|---|
| 근거 | `04_사업장폐기물위탁처리명세_2026-04.pdf#1` — 재활용 5,400 + 소각 6,100 + 매립 6,900 = **18,400 kg** |
| 초안 판단 | 외부 **위탁 처리 전체** 기준. ÷1000 = 18.4 톤 |
| 제외한 것 | `08_공정스크랩관리대장_2026-04.pdf#1`의 내부 재투입 11,500 kg (04·08 양쪽에 분리 명시) |
| 쟁점 | "배출량"을 **외부 위탁 기준**으로 볼지 **발생량 기준**으로 볼지. 발생량이면 분모가 달라진다 |
| 단위 | 원본 kg → 문항 요구 톤. 같은 측정량·기간·대상의 정확한 환산이라 `answer`로 두었다(가정이 들어가지 않는다) |
| 독립성 | **A는 이 문항의 ESGenie 응답(18.4 톤)을 미리 보았다.** 같은 값이지만 독립 산출이라고 주장하지 않는다 |

## 3. `hold` 사유 구분 — `no_evidence`인가 `not_comparable`인가

### 3.1 `RBA-C-8-E-4-1` 에너지 사용량(TJ) — 초안 `hold` / `not_comparable`

| 항목 | 내용 |
|---|---|
| 있는 것 | `02_전기요금청구서_2026-04.pdf#1` 142,560 kWh · `03_도시가스요금고지서_2026-04.pdf#1` 8,420 m³ |
| 없는 것 | **발열량·보정계수** — `03`이 "제시하지 않는다"고 명시한다. TJ 환산에 가정이 필요하다 |

## 5. 쟁점이 없다고 본 행 — 참고

나머지 16행 중 14행은 `hold`/`no_evidence`이고, 사유가 "해당 주제를 다룬 문서가 세트에
아예 없다"는 단순한 것이다 — `RBA-A-6` 결사의 자유, `RBA-B-7` 위생·기숙사, `RBA-C-1`
환경 인허가, `RBA-C-5` 대기배출 모니터링, `RBA-C-5-E-7-1` 대기오염물질,
`RBA-C-8-E-4-2` 재생에너지, `RBA-E-12` 공급사 행동규범 (각 2행).

남은 2행은 `RBA-E-8`(`answer`/`예`, `10_윤리경영및고충처리규정_2026.pdf#1` 제2·3·4조).
근거가 문항 요건을 직접 덮어 표시하지 않았지만, **§1.3의 "규정 문서만으로 실시를 인정할
수 있는가" 결정에 함께 걸린다.** 그 결정이 바뀌면 이 행도 바뀐다.

**그래도 사람 검토 없이 확정하지 않는다.** "문서가 없다"는 판단도 14건을 다 읽었다는
전제에 의존하고, AI가 놓친 문구가 있을 수 있다.

## 6. followup 단계

16행 중 followup 8행은 모두 initial과 같은 판단이다. 보완 증빙
`13_안전보건추가교육실시기록_2026-04-27.pdf`가 **안전보건 교육 출석 기록**이라 위
문항들과 무관하기 때문이다. 각 행 `note`에 그 이유를 적었다.

**initial 라벨에 13번을 섞지 않았다.** followup 행은 13번을 포함한 상태로 다시 판단했고,
결과가 같은 것과 판단을 생략한 것은 다르다.
