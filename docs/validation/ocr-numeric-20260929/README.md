  (전기 배율 필수, 가스 환산 계수 없음). 폐기물 구성 합계·명세 합계·재활용률 반올림 검산. 표/텍스트 요소 bbox를 PDF 문자 좌표로 좁힘.

- 범위 밖(작업지시서 명시): 본문만 있는 금액의 일반 해석, 홈페이지·대시보드, 고객 요청 모델, 사용자 범위 선택.
