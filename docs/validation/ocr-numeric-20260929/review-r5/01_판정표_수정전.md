## 1. 원인 (작업지시서 §2 확인)

- `3adb047`의 `_is_absent_marker`는 문구 **일부**에 `예정·추후·미정·미확인·없음` 등이 있으면 칸 전체를 값 없음으로 보았다. `납부예정금액`도 값 없음이 된다.
- `_classify_row`는 부재 표시 칸을 건너뛰고 첫 유효 칸으로 행을 판정한다 → 항목명이 사라지고 `247,500`만 남아 앞 표 `사용열량(MJ)` 열 위치를 이어받았다.
- 같은 판정이 정상 혼합 표에서는 항목명 `납부예정금액`을 물리량의 행 이름으로 남겼고, 힌트 `도시가스 사용열량 (납부예정금액)`의 `예정`을 경계 판정(`detect_basis`)이
  계획값으로 읽어 답변이 `insufficient`가 되었다(아래 §3, 새 발견).
- 분류: **`3adb047`에서 생긴 회귀**. 같은 입력의 `06a1433`에서는 금액 행이 `money_row_excluded`로 빠졌다.

## 2. 판정표(작업지시서 §4.3) → 적용할 기준

| 셀·행 문맥 | 기대 | 적용할 기준 |
|---|---|---|
| 수치 칸의 빈 문자열·대시·`N/A` | 값 없음, 다른 칸 숫자로 채우지 않음 | 공백·괄호를 정규화한 뒤 칸 **전체**가 비었거나 구두점뿐이면 부재 |
| 수치 칸의 `검침 예정`·`측정 예정`·`미검침`·`미정` 등 완결된 상태 표현 | 값 없음 또는 기존 계산 보류, 지침 계산 유지 | 칸 전체가 완전 일치 집합(`미정`·`미검침`·`해당없음`…) 또는 제한 문법(`(검침·측정·계량·산정·집계·확인·입력·기재·통보)(예정·중·전·대기)`, `추후(…)`, `(값·자료·데이터)없음`)에 맞을 때만 부재. 부분 문자열로 True를 내지 않는다 |
| `납부예정금액`·`청구예정금액`·`추후청구요금` + 별도 금액 숫자 | 항목명으로 유지, 금액 행 처리, 물리량 미생성 | 위 기준에 맞지 않으므로 부재가 아니다 → 행 머리로 남아 `3adb047`의 구조 판정(항목 열 없는 표의 수량 열 글자 = 구조 불일치 행, 금액 이름이면 `money_row_excluded`)으로 간다 |
| `검침예정일` 같은 의미 있는 항목명 | 부재 아님, 역할 또는 보류 사유 유지 | 부재 아님 → 금액 이름도 아니면 `row_label_in_quantity_column`(그 행만 보류) |
| 정상 혼합 표의 항목명이 `납부예정금액` 등 | 열 관계대로 물리량 보존, 금액 칸만 제외, 행 삭제 금지 | `3adb047`의 요금 명세 행 판정 유지. 그 행의 항목명은 **금액 칸의 이름**이므로 물리량의 `row_label`(힌트·경계 판정 입력)로 쓰지 않고 `row_item`으로 따로 기록 |
| 기간·계량기 식별값에 `예정` 등이 함께 있음 | 범위 보존 | 범위 열은 머리글 기준(`_label_axis`) 그대로. 부재 판정은 수치 칸에만 영향 |
| 역할이 불명확한 글자 셀과 옆 숫자 | 글자를 지우고 옆 숫자를 채택하지 않음, 그 후보만 보류 | 목록·문법에 없는 문구는 부재로 단정하지 않는다: 수치 칸이면 `value_not_numeric`, 행 머리면 `row_label_in_quantity_column` |
| 명시 0 | 수치 | 부재 판정과 무관(숫자 칸) |

`_is_absent_marker`가 True = "값 없음 표시라서 건너뛸 수 있음". False = "값 없음 표시가 아님"이며 **수치라는 뜻이 아니다** — 숫자 해석은 따로 한다.
