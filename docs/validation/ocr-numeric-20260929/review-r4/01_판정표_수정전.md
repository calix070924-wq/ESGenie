# R8 재보완 — 구현 전 판정표와 수정 전 결과 (2026-09-30)

구현 전에 작성했다. 작업지시서 §2 판정표의 원문 관계를 표 해석 규칙으로 옮기고, 최소 입력의 수정 전 결과를 고정한다.

## 1. 판정표 → 적용할 해석 기준

| 확인된 원문 관계 | 기대 처리 | 적용할 기준(구현 예정) |
|---|---|---|
| 사용량·열량 열에 정상 수치가 있고 금액 열이 별도로 있음 | 항목명에 요금 단어가 있어도 사용량·열량 셀 보존, 금액 셀은 에너지 근거에서 제외 | 행을 항목명만으로 지우지 않는다. 머리글이 금액인 열(`요금(원)`·`청구금액` 등)이 그 행에 값을 갖고 있으면 그 행은 "요금 명세 행"이다 — 물리 역할 열의 셀은 그대로 읽고, 금액 열 셀만 제외 기록에 남긴다 |
| 앞선 사용량 표 밑에 금액 항목명과 청구 숫자만 있는 별도 행 | 앞선 표의 물리 단위를 상속하지 않음 | 항목 열이 없는 표(첫 머리글이 물리 역할)에서 물리 역할 열에 **숫자가 아닌 글자**(비어 있음 표시 제외)가 있으면 그 행은 머리글 구조에 맞지 않는다 — 행 전체를 데이터로 쓰지 않는다. 금액 이름이면 `money_row_excluded`, 아니면 `row_label_in_quantity_column`(보류). 단어 목록에 없는 `기본료`·`사용료`·`계량기 교체요금`도 구조로 걸러진다 |
| 항목 열이 있는 표에서 금액 이름 행, 금액 열 없음 | 금액을 물리량으로 만들지 않음 | 금액 이름(단어 목록 + `…료` 비용 접미, `(원)`)이면 행 제외. 단어 목록은 구조 판정을 보조하는 두 번째 근거다 |
| 계량기·사업장·기간 열의 실제 범위 식별값 | 범위로 보존 | `_label_axis`는 **머리글**(범위 열)에만 쓴다. 행 이름에 ‘계량기’가 들어 있다는 이유로 금액 판정을 면제하지 않는다. 기간 열에서 날짜 형식(`2026년 5월`, `2026-05`)이 있는 값만 기간 식별값으로 면제한다 |
| `계량기 교체요금`처럼 비용 항목 | 면제하지 않음 | 위 기준 — 금액 이름이고 날짜 형식 기간값이 아니면 금액 |
| 열·행 관계를 확정할 근거가 부족함 | 해당 후보만 보류, 사유 보존, 다른 확정값 유지 | 금액 이름 행인데 금액 열 칸이 비어 있고 물리 칸에만 숫자가 있음 → `money_label_row_unconfirmed`로 그 행만 보류. 템플릿 후보가 제외 셀과 같은 숫자여도 좌표·쪽이 다르면 유지하고, 좌표가 없어 동일성을 확인할 수 없으면 삭제 대신 보류 사유를 남긴다 |
| (부수) 머리글 `사용량(m3)`의 3 | 값이 아님 | 템플릿이 키워드 토큰 안의 숫자를 값으로 쓸 때 머리글 단위 괄호(`(m3)`·`(tCO2eq)` 등)를 먼저 뺀다 |

금액 제외는 원문 셀 단위로 기록한다(`money_cells`: 값·원문·좌표·쪽·표). `247,500원`·`₩247,500`처럼 통화 표기가 붙은 칸도 같은 기록에 넣는다.
