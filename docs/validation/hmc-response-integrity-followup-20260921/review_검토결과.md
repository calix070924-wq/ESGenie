## 무엇이 바뀌었고, 무엇은 잘됐나

1. **측정 범위가 데이터에 따라다니도록 확장했다.** 기간 집계 방식, 사업장, 에너지원, 부분/전체, 실적/계획 정보를 노드에서 원장·응답·표시까지 전달한다. 동일 기간 전기 142,560 kWh와 가스 360,772 MJ의 제한적 합 0.873988 TJ는 회귀에서 확인된다. 월간값을 12배로 만들지 않는 점도 맞다.
2. **재생에너지 구성비와 전체 비율을 구분하기 시작했다.** 태양광 5.6%를 전체 재생에너지 비율로 자동 검증하던 경로를 막았다. 다만 전체 비율의 검증 자격은 아래 F3처럼 불완전하다.
3. **대조 상태를 네 가지로 나눴다.** 대조 완료·실제 불일치·비교 불가·범위 확인 필요를 표시한다. 폐기물 주장 92%와 증빙 29.3%는 검토필요로 표시된다. 다만 상태를 정하는 순서와 체크리스트 전달에 구멍이 있다.
4. **UI·Excel·PDF 표시 규칙을 공통화했다.** 4분할 집계, 자연 정렬, 유효한 소수 자릿수, 범위·검토 열, 번호 인용은 유용한 개선이다. 확인한 PDF에서 비교 기호가 `vs`로 읽히며 기존 빈 네모 문제는 해결됐다.
5. **문항 목적에 맞는 증빙 안내를 추가했다.** 공정거래·환경 인허가 등에 정량 고지서를 요구하던 안내를 개선했고 C-5를 관리체계와 배출량 문항으로 분리했다. 공통 RBA 정의 변경이므로 HMC와 RBA 양쪽 문항 수가 바뀐다.
6. **초안 작성 전 문항 어휘로 근거를 좁힌다.** 코드 일치 경로와 검색 폴백 모두 적용된다. 실제 문서 10개를 E-7에 모두 태깅한 실험에서 의사소통절차서만 남는 효과는 재현됐다. 이것이 모든 입력에서 관련성이나 생성 문구의 정확성을 보장하지는 않는다.

## 보고서에 남긴 한계에 대한 평가

- **E-8 잡음 통과:** 실측을 재현했다. 6개 중 정보보호·근로시간·위생 문서가 살아남는다. E-7도 정보보호 문서만 주면 통과하는 한계가 있다. 좋은 후보가 같이 있어야 상대 하한이 잡음을 걸러내는 구조다. '원래 조합에서는 개선'과 '일반적으로 해결'을 구분해야 한다.
- **추가 LLM 관련성 호출을 넣지 않은 결정:** 결정적 검사로 해결할 수 있다면 합리적인 비용 선택이다. 다만 현재의 어휘 검사가 관련성 보장의 완료 근거가 되지는 않는다. 증빙 말뭉치 빈도는 가능한 개선책이며 유일한 해결책이라고 검증되지는 않았다.
- **222문항 판정 불가 0:** 모든 문항에서 비교할 어휘를 만들었다는 뜻이다. 222개 문항에 대한 정답 정확도·재현율을 검증했다는 뜻은 아니다.
- **C-2/C-7 수치 문항:** 양식 설계 검토가 필요하다. 확인한 코드에서 C-7은 실제로 존재하지 않는 별도 수치 문항을 안내한다. C-2의 현재 안내문에는 그 문구가 없어 보고서 표현도 구분할 필요가 있다.
- **옛 JSON·정상 전체 비율 테스트:** 새 회귀는 DataPoint의 `verification='verified'`, `completeness='total'`을 직접 넣어 Answer 전달을 확인한다. 실제 경계 추출부터 정상 전체성을 입증하는 검사와는 범위가 다르다.
