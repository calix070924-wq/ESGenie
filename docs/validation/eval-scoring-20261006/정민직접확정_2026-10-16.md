# 독립성·E-11 범위 — 정민 직접 확정 (2026-10-16)

## 결정 출처와 우선순위

정민이 이 Codex 대화에서 직접 다음과 같이 지시했다.

> 그럼 네 권고대로 확정하고, 독립성 집계랑 A/B 기록·보고 문구도 네가 맞춰서 수정해줘. E-11 범위 확인 대기도 해제해줘.

이 지시는 바로 앞 권고(아래 결정)를 승인한 것이다. 10월 15일 전달 기록의 독립 인정·본인 확인 대기와 E-11 범위 대기를 대체한다.
A가 이미 반영한 10월 16일 제외·AI 참고 처리와 같은 결론이며, 이번에는 전달자 경유가 아닌 본인 직접 확정으로 기록한다.
이전 결정 원문, 라벨 작성 전 열람 기록, 작성자 진술과 원본 답안지는 수정하지 않는다.

## 확정한 결정

1. **B 5문항은 독립 일치율에서 제외한다.** 대상은 RBA-C-8-E-3-1, RBA-E-11, RBA-E-12,
   RBA-C-5-E-7-1, RBA-C-8-E-4-2의 초기·보완 단계다. 사전 사례 분류 노출 기록과 작성자 진술의 충돌을
   해소하지 못했으므로 기존 `unverifiable`(독립성 확인 불가로 제외) 분류를 유지한다. 본인 승인이
   독립성을 새로 입증한 것은 아니다. 최종 정답 라벨로 사용하는 것과 독립 검증 인정 여부는 별개다.
2. **hjm은 AI 단독 참고 검토다.** Gemini 단독 초안이고 사람 수정이 없으며 요청서·보완 13번·범위표를
   받지 않았다. 초기·보완 모두 공식 사람 독립 검토 집계에서 제외하고 AI 참고 기록으로만 보존한다.
3. **E-11 범위는 최종 확정한다.** 개인정보 요소는 A-08의 2026-04-30 기준·두 공장,
   그 밖 문서·기록 생성·유지 요소는 2026년 4월·김해 제1공장으로 정한다. 문항 전체를 A-08에 연결하지 않는다.
   범위 확인 대기와 관련 미결 질문을 해제한다. E-11 B 라벨의 독립성 제외는 그대로다.
4. **최종 라벨과 성능 채점 결과는 유지한다.** 이번 수정은 독립성·범위 상태와 보고 문구의 확정이다.
   평가 입력, 라벨 값, v1·v2 채점 결과를 바꾸거나 새로운 AI 실행을 하지 않는다.

14/14, 보류 사유는 4/12, 값은 10월 10일 수정본 기준 2/2(최초본 0/2)다.
수치형 독립 일치율은 0%가 아니라 산출 불가다. **독립 검증은 부분 완료**이며, 공식 표본의 제외 행과
수치형 전수 집합에 사람 독립 검증이 부족하다는 한계는 대기 해제 후에도 남는다.
