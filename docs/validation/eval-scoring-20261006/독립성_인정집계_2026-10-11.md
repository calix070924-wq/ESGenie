# 독립 검토 인정 집계와 A·B 원값 대조 (2026-10-11, B 열람확인 보완 회신 반영)

정민 보완 지시서(2026-10-11) A2에 대응한다. 같은 날 저녁 B의 문항별 열람확인 보완 회신을 반영해 이 문서를 갱신했다. 이전 판(B 독립 인정 0행)은 git 이력에 있다.

**결론.** 공식 20행은 B(사람) 독립 20행이 확인됐다. 수치 전수 12행은 독립 6행·노출 제외 2행·확인 대기 4행이다. 확인 대기 4행(RBA-C-4-E-6-1, C-8-E-4-1 × 두 단계)은 B가 본 "함정 유형 설명"을 기대 판정 노출로 셀지 정민이 정해야 풀린다. **독립 표본 요건은 공식 집합에서 B 쪽 기준으로 충족됐다. 단, A 쪽 문항별 열람확인은 A가 신고한 4문항 외에는 별도 확인 기록이 없다.** 아래 일치율은 "협의 전" 값이며 협의 결과(A 라벨 유지)와 구분한다.

## 2. 반영한 열람 기록

### 2.1 B 회신 2026-10-09 (유지)

초안 AI(Claude Code 세션)가 라벨링 가이드의 RBA-C-4-E-6-2 "29.3%/92%" 언급을 읽었고, 사람 B가 그 초안을 원본과 대조해 검토했다. 그래서 RBA-C-4-E-6-2는 `expected_value` 노출 행으로 센다(기존 행 유지).

### 2.2 B 회신 2026-10-11 열람확인 보완

B는 기억에만 기대지 않고, 라벨 작성 시작(10/9 14:13) 전까지의 작업 대화 기록(검사 담당 대화, Claude Code 세션 1·2 화면 출력)을 15개 문항 ID로 검색해 확인했다. 원문은 이 저장소에 없다(지민이 전달한 회신).

| 문항 | ESGenie 응답 / 기대값 / A 라벨 초안 | 기록 상태 |
|---|---|---|
| RBA-C-4-E-6-2 | 예 / 아니오 / 아니오 | `system_answer` 행 추가 → **노출 제외**. 10/6 B-1 출력 검사기 보고에 ESGenie 응답서 셀 값이 나왔다. 작업지시서_B §4.1 함정 표의 04/08/05 수치 설명도 읽었다. 기존 `expected_value` 행은 유지 |
| RBA-C-8-E-4-1, RBA-C-4-E-6-1 | 아니오 / 아니오 / 아니오 | **`unconfirmed`(확인 대기, 정민 판단)** — 작업지시서_B §4.1 "부분 범위" 함정 설명(에너지: 전력만·가스 미포함 / 폐기물: 4월·제1공장)을 읽었다. 응답·기대값·초안은 보지 않았다 |
| RBA-C-8-E-3-1, E-11, E-12, C-5-E-7-1, C-8-E-4-2 | 아니오 / 아니오 / 아니오 | `none`(독립). B-3 사례 분류(증빙 원본만 보고 붙인 유형, ESGenie 응답·A 라벨 아님)를 대화에서 봤다: C-8-E-3-1 함정 후보 추가 / E-11 normal / E-12 partial_scope / C-5-E-7-1·C-8-E-4-2 증빙 부재 확인 |
| RBA-A-6, B-7, C-1, C-5, E-2, E-3, E-8 | 아니오 / 아니오 / 아니오 | `none`(독립). 기록 검색에서 결과·분류 언급 없음. A-6·E-8은 사용법 안내의 입력 예시로만 나왔다 |

초안 AI에 대해서도 확인됐다.
- 10/9 13:04에 새로 연 Claude Code 세션으로 **B-1 세션과 다른 세션**이며 작업 폴더도 다르다. 도구 기록상 ESGenie 결과(result.json·exports·outputs/eval)나 정답 포함 폴더를 연 기록이 없다. 읽은 것은 라벨링 폴더 파일과 작업 메모뿐이고 작업 메모에 문항별 결과는 없다. B-1에서 본 내용은 라벨 판단에 쓰이지 않았다고 B가 답했다.
- "29.3%/92%"의 출처는 A 전달 패키지가 아니라 작업지시서_B(2026-10-05) §4.1 함정 표이고, B 검사 담당이 이를 B 쪽 `라벨링_가이드.md` §7-1과 `체크리스트_사용법.md` §6의 열람확인 예시로 옮겨 적었다. 이 저장소에는 두 B 쪽 문서도 없어 대조하지 못했다.
- 초안 AI가 본 문구에 "일부 문항 ID 목록"이 있었다고 했으나 어느 문항인지는 적히지 않았다.

### 2.3 이번 회신을 읽는 방식
- "기록을 검색해 보지 못했다"는 기억에 의한 "본 기억 없음"보다 강한 확인이지만, 기록에 남지 않은 열람까지 증명하지는 못한다. 그래서 `none`의 사유에 "작업 대화 기록 검색 기준, 기억 아님"으로 적었다.
- B-1 AI 세션의 노출 기록(출력 검사 보고 48문항 전체)은 그대로다. 그 노출이 사람 B에게 전달된 경로는 위에 적은 C-4-E-6-2의 셀 값 하나뿐으로 확인됐다.

## 3. 집합별 독립 인정 상태

| 집합 | 라벨러 | 원표본 | 독립 인정 | 노출 제외 | 확인 대기 | 비고 |
|---|---|---|---|---|---|---|
| 공식 `bm_rba42_v1` | B (사람) | 20 | **20** | 0 | 0 | |
| 수치 전수 `bm_rba42_numeric_census` | B (사람) | 12 | **6** | 2 | **4** | 제외: C-4-E-6-2(두 단계). 대기: C-4-E-6-1, C-8-E-4-1(두 단계) |
| 공식 | B-1 (AI) | 20 | 0 | 20 | 0 | 10문항 전부 |
| 수치 전수 | B-1 (AI) | 12 | 0 | 12 | 0 | 6문항 전부 |
| 공식 | A | 20 | 0 | 2 | 18 | 제외: C-8-E-3-1. 나머지는 A 쪽 확인 기록 없음 |
| 수치 전수 | A | 12 | 0 | 8 | 4 | 제외: C-4-E-6-1, C-4-E-6-2, C-8-E-3-1, C-8-E-4-1 |

- 두 집합은 `RBA-C-8-E-3-1` 1문항(2행)이 겹친다. 고유 행은 20+12−2 = **30행**이다. **30행의 무작위 독립 표본이라고 부르지 않는다** — 수치형 12행은 무작위가 아니라 전수다.
- A 행의 "확인 대기"는 A가 노출을 신고하지 않은 문항에 대해 A 쪽 열람 확인 기록이 따로 없다는 뜻이다. A가 해당 문항을 열람하지 않았다고 확인하면 `none` 행으로 채우면 된다.

## 4. 협의 전 A·B 원값 대조

`AB_원값대조_요약_2026-10-11.json`의 값이다. 세 가지 부분집합을 구분한다. **"전체"는 독립 일치율이 아니다.**

| 집합 | 부분집합 | 행 | 판정 일치 | hold 사유 일치(둘 다 hold) | 값 일치(둘 다 answer, B 10/9 원본 / 10/10 수정본) |
|---|---|---|---|---|---|
| 공식 20행 | 전체(노출 제외 전) | 20 | 20/20 | 6/16 | 0/4 / 4/4 |
| 공식 20행 | B 독립 인정 행 | 20 | 20/20 | 6/16 | 0/4 / 4/4 |
| 공식 20행 | B 독립 + A 신고 노출 행 제외 | 18 | 18/18 | 4/14 | 0/4 / 4/4 |
| 수치 전수 12행 | 전체(노출 제외 전) | 12 | 12/12 | 8/8 | 2/4 / 2/4 |
| 수치 전수 12행 | B 독립 인정 행 | 6 | 6/6 | 6/6 | 산출 불가(분모 0) |
| 수치 전수 12행 | B 독립 + A 신고 노출 행 제외 | 4 | 4/4 | 4/4 | 산출 불가(분모 0) |

- 값 칸 10/9 원본 0/4는 B가 answer 4행의 값 칸을 비워 둔 결과이고, 10/10 수정본은 그 칸에 "예"만 채웠다(판정·사유는 같다). 값 일치는 문자열 비교이며 단위 환산을 하지 않는다.
- hold 사유 불일치 10행: 공식 집합의 RBA-A-6, C-1, E-12, E-3, E-8 × 두 단계. A `no_evidence` / B `not_comparable`. **협의 결과: A 라벨 유지**(정민 결정 2026-10-10, 지민 전달). 근거: 요건 일부에만 증빙이 있는 보류를 A는 `no_evidence`로 부른다. B 라벨은 협의 전 값으로 보존했다. 독립 행만 보아도 사유 일치율이 낮다(6/16, 4/14)는 점을 숨기지 않는다.
- 수치 전수 값 불일치 2행(전체 기준): RBA-C-4-E-6-1 두 단계. A `18.4 톤` / B `18,400 kg`. 같은 양을 다른 단위로 적었다. 이 문항은 확인 대기라 독립 부분집합에서는 빠져 있다.
- 공식 20행과 수치 전수 12행을 합친 일치율은 만들지 않는다.

## 5. A 쪽 한계

A는 RBA-C-4-E-6-2(기대값·시스템 응답), RBA-C-4-E-6-1·C-8-E-4-1·C-8-E-3-1(시스템 응답)에 과거 노출이 있다(PR #71 작업 중, 본인 신고). 이 4문항(두 단계 8행)의 A 최종 라벨은 원본으로 다시 확인했지만 독립 라벨이 아니다. **새 실행 결과를 라벨 커밋 뒤에 열었다는 순서만으로 이 과거 노출이 없어지지 않는다.** 위 표의 "A 신고 노출 행 제외" 부분집합이 이 한계를 반영한 값이다.

## 6. 정민에게 보고할 것과 다음 조치

1. **B 독립성:** 공식 20행 독립 확인(B 기준). 수치 전수는 독립 6·제외 2·대기 4.
2. **정민 판단 필요:** 작업지시서_B §4.1 "부분 범위" 함정 설명(문항 유형 설명)을 읽은 것이 기대 판정 노출인지. 노출로 보면 C-4-E-6-1, C-8-E-4-1이 제외로, 아니면 독립으로 바뀌고 수치 전수 B 독립은 6→10행이 된다.
3. **A 쪽 확인:** A가 신고한 4문항 외 문항에서 ESGenie 응답·기대값을 보지 않았다는 A 본인의 문항별 확인이 기록에 없다. A(지민)가 확인하면 기록한다.
4. **B에게 남은 확인:** (a) 초안 AI가 본 문항 ID 목록이 어느 문항이었는지, (b) 회신의 "값은 없었습니다"와 "29.3%/92% 언급"이 같은 문서 안에서 어떻게 구분되는지, (c) B 대조군 실행 입력 ZIP 해시.
5. 비독립 라벨이 최종 정답으로 쓰일 수 있는지와 독립 일치율 인정 여부는 별개 판단이다.
