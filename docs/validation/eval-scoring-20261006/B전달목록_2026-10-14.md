## 3. 실행 조건 — 재채점인가 재실행인가

- 이번 확정에서 **라벨 값은 바뀌지 않았다.** 범위표는 라벨 판단의 기준을 기록한 것이며 모델 입력이 아니다.
- 고객 요청안내(`00_`)는 ESGenie·B 대조군 실행 입력에 들어가지 않았다(2026-10-11 기록). B가 대조군 프롬프트에 요청 범위 정보를 넣지 않았다면 **모델 입력 변화가 없으므로 재실행 없이 저장 응답을 재채점**한다. 넣었다면 그 내용을 A·정민에게 먼저 알리고 동일 조건 재실행 계획을 정한다.
- 결과에 함께 적을 것: 대조군 실행별 응답 파일 sha256, 입력 묶음 ZIP sha256, 프롬프트·하네스 커밋, 모델 응답 기록명, `05_` 인용 행 수, 사용한 라벨·채점기 커밋.
- ESGenie 쪽: 저장 결과 `LIVE_n5_d8a0de8`(제품 `d8a0de8`)의 재생 채점이며 `5b335e0` 신규 실행이 아니다. 신규 실행 여부는 정민 결정 사항으로 남는다.
