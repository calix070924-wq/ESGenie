## 한계

1. 같은 모델 계열이지만 같은 시스템 비교는 아니다. 차이에는 검증 구조와 프롬프트 차이가 함께 들어 있다.
2. 팀이 만든 가상 세트 1개·프롬프트 v1 1개·모델 1개 결과다. 일반화하지 않고 "N배" 표현을 쓰지 않는다.
3. temperature 0 이어도 반복 간 판정이 바뀌는 행이 있다(initial M2 14~18).
4. ESGenie 는 1회 실행이고 OCR 을 새로 해 대조군 입력과 2개 파일에서 표기가 다르다. v2 는 결과를 본 뒤 정한 규칙이고 보류만 재분류한다.
5. 독립 검증은 부분 완료다(공식 B 사람 독립 14/20행·수치형 0/12행). B 5문항은 독립성 확인 불가로 제외하며,
   hjm은 AI 단독 참고 검토다. 독립성 인정·hjm 처리·E-11 범위의 결정 대기는 해소됐지만 독립 검증의 부족은 남는다.
6. 범위표 교차검토는 B 세션 AI 가 원문 대조한 결과이며 사람 확인 전이다. 갱신본(`0332a68`)은 B 항목 반영 여부만 확인했다.
