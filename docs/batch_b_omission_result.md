> SME001/SME002는 샘플/시나리오 리포트. 각 케이스는 해당 리포트가 **실제로 공시하지 않은** 지표에 대한 주장 → 주입 없이 그 그래프에서 no_evidence 자연 발동.

## 0. 데이터 무결성 감사 (expect 대비 실제)

- ✅ 전부 의도대로 동작 (no_evidence 자연 발동 15건, 문제 0건)

## 1. 전역 지표 (OFF vs ON)

| 해석 | Coverage | Accuracy(assessed) | Overall | 기권수 |
|---|---|---|---|---|
| OFF (기권 무시) | 1.000 | 0.571 | 0.571 | 0 |
| ON  (기권 반영) | 0.286 | 1.000 | 0.286 | 15 |

- 사유별 기권: {'no_evidence': 15, 'unit_mismatch': 0, 'low_confidence': 0}
- ΔAccuracy(assessed) = +0.429 · ΔCoverage = -0.714 · ΔOverall = -0.286

## 2. 기권 분해 — 가치(save) vs 비용(waste)

- 총 기권 15건 = save 9건 + waste 6건
- **save**(OFF면 틀렸을 미탐 → 검토 구제): ['B-GW-01', 'B-GW-02', 'B-GW-03', 'B-GW-04', 'B-GW-05', 'B-GW-06', 'B-GW-07', 'B-GW-08', 'B-GW-09']
- **waste**(OFF면 맞았을 것 → 불필요 검토): ['B-CL-01', 'B-CL-02', 'B-CL-03', 'B-CL-04', 'B-CL-05', 'B-CL-06']
- **기권 정밀도 p = 0.600** · 손익분기 **B/R > 0.6667**

> **p는 성능 지표가 아니다**(2026-08-03 정정): no_evidence 기권은 content-blind다 — 노드
> 유무로만 발동하고 주장의 참/거짓을 보지 않는다. 따라서 기권 케이스에 어떤 라벨을 붙여도
> abstain은 참·거짓을 동일하게 전부 기권하므로, p는 구조적으로 이 파일럿의 라벨 구성비
> (greenwash:clean = 9:6)와 같아진다 — relabeling으로 해소되지 않는다. 근거가 있을 때의 실제
> D1 성능은 진위 holdout(`data/benchmark_v2/batch_c_truth_holdout.json`,
> `scripts/d1_truth_eval.py`)으로 별도 측정한다.

## 3. probe(주입) 대비 — 이 샘플 리포트가 말해주는 것

probe(005930 단일 그래프에 omit_codes 주입)와 달리 이 배치는 서로 다른 회사(샘플/시나리오 리포트)의 **실제 공시 공백**에서 no_evidence가 자연 발동했다 — 주입 없이도 기권 메커니즘이 동일하게 작동함을 확인. 이로써 '현행 벤치는 미공시를 관측 못 한다'는 감사 결론의 해법(배치 B)이 실제로 성립함을 실측으로 입증했다(자연 no_evidence 15건). (p 수치 자체의 성능 지표 여부는 위 §2 주의 참조.)

## 4. 판정 · 다음 단계

샘플/시나리오 리포트에서 no_evidence 기권이 15건/21 자연 발동했고(현행 dev/test는 0건이었음), 그중 미탐 9건을 사람 검토로 전환하며 자동판정 정확도를 +0.429 끌어올렸다. Overall(-0.286)은 이 설계에서 구조상 오를 수 없으므로 여전히 채택 판정 기준이 아니다. **정밀도 p(0.600)도 채택 판정 기준이 아니다** — content-blind 기권은 구성한 라벨 비율을 그대로 반영할 뿐 모델 성능이 아니다. 이 하네스가 검증하는 것은 '정확한 발동(§0 무결성 감사)'과 'Accuracy(assessed)/Coverage 트레이드오프'뿐이며, 근거가 있을 때의 실제 D1 성능은 진위 holdout(`scripts/d1_truth_eval.py`)으로 별도 측정한다. 다음 단계: (1) 이 셋을 실키 회귀에 편입해 실측 고정, (2) HITL 라우팅을 붙여 '기권→검토'를 실제 동작으로 연결, (3) 진위 holdout 확충으로 D1 실성능 신뢰구간 확보.
