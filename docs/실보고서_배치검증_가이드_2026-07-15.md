## 3. 실행

```bash
# 0) 스모크 테스트 — 1개사 먼저 (강력 권장)
ESGENIE_STRICT=1 python scripts/batch_validate_real_reports.py --only 009150

# 1) 전체 배치 (PDF 준비된 회사만 실행, 없으면 skip)
ESGENIE_STRICT=1 python scripts/batch_validate_real_reports.py

# 옵션: --llm-judge (하이브리드 검출, 비용↑) / --export-report (통합 보고서 생성)
```

결과: `outputs/batch_validation_<날짜>.json` + 콘솔 요약 테이블.
에러는 traceback 그대로 JSON에 남는다 — 그게 이 작업의 산출물.

## 4. 비용·시간 주의

- 보고서 1권이 100p+ — 비정형 OCR(gpt-4.1-mini) 비용·시간이 한울정밀 증빙 20건보다 훨씬 큼.
  **반드시 1개사 스모크로 페이지당 처리 시간·비용 감 잡고 전체 실행할 것.**
- 너무 크면 보고서에서 환경·사회 섹션만 분할한 PDF로 대체하는 것도 방법
  (pdftk/pypdf로 페이지 분할 — 단, 그 경우 커버리지 해석 시 감안).
