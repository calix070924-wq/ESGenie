## 2. 수정 내용

### A [P1] 복합 단위·지표 의미

- 숫자 뒤 단위를 **표현 전체**로 읽는다(`_read_unit`): `/`·공백·숫자·지수·첨자 포함
  (`MJ/톤`, `MJ / 톤`, `m3`, `m³`, `m^3`, `tCO2eq`). 분모가 있으면 복합 단위로 표시하고
  단위 그룹을 정하지 않는다 — `MJ/톤`은 `MJ`로 읽히지 않는다.
- 조사는 허용 목록(`_UNIT_PARTICLES`)의 하나만 떼고 다시 정규화한다. 모르는 접미사는
  조사로 보지 않는다(`MJx` → 단위 미확인).
- 지표 동일성과 단위 동일성을 따로 본다. 총량과 원단위·평균·누계·비율·증감·목표는
  낱말이 포함돼도 같은 지표가 아니다(`_metric_kinds`). 같지 않으면 `metric_unproven`.
- `_evidence_amounts_in_unit`도 같은 단위 판정(`_trailing_unit` → `_read_unit`)을 거치므로
  복합 단위 금액은 후보가 되지 않는다.
- 보정 기록에 원문 단위 표현(`source_unit_text`)을 추가했다. 기존 원문 단위·라벨·보정 전후
  값·후보·사유·인용·쪽·기간 기록은 유지한다.

### B [P2] 0 근거의 기간·사업장

- 기간을 실제 범위로 읽는다(`_date_spans`): 일(`2026-04-30`, `2026년 4월 30일`), 월
  (`2026-04`, `2026.04`, `2026년 4월`), 연(`2026년`), 구간(`2026-04-01 ~ 2026-04-30`,
  `2026-04-01~04-30`, `부터`).
- 관계(`_period_relation`): 같은 범위 → 일치 / 겹치지 않음 → `period_mismatch` /
  겹치지만 범위가 다름(기준일 ↔ 한 달, 연간 ↔ 한 달) → `period_unproven` / 읽지 못함 →
  판정하지 않음. 한 시점을 월로, 연도만을 월로 확대하지 않는다.
- 사업장은 지역·번호까지 정규화한 식별값으로 비교한다(`_site_keys`). 공백·조사·`제`
  띄어쓰기만 같게 본다. 부분 문자열 비교를 없앴다(`아산공장` ≠ `서아산공장`), 지역 없는
  `제1공장`으로 `김해 제1공장`·`부산 제1공장`을 고르지 않는다.
- 숫자 0 경로도 명시적 기간·사업장 불일치면 채택하지 않는다.
- `measurement_context.period_bounds()`/`site_path()`는 단일 날짜를 읽지 못하고 지역명을
  떼므로 쓰지 않고 이 경로 전용 함수를 두었다.

### C [P2] 부정 서술의 사실성

- 부정 어근 발견(`_ZERO_NEGATION_RE`)과 사실 판정(`_negation_mood`)을 분리했다.
- 연결 어미(`-며`·`-고`·`-으나`·`-지만`·`-는데`·`-면서`)로 서술을 나눠 현재 상태와 뒤의
  계획을 구분한다. 인용 어미(`-다고`·`-다며`)는 경계로 보지 않는다.
- 판정 범주: 사실(채택) / `future_or_intent` / `not_confirmed` / `evidence_insufficient` /
  `negation_negated` / `interpretation_unknown`. 사실로 판정한 뒤 B의 기간·사업장 대조를
  통과해야 채택한다.
- 0을 보유(1)로 승격하는 경로는 없다. 새 LLM 호출은 없다.

### 기록·표시

- `zero_not_in_evidence` 기록에 `cause`, `metric_site`, `evidence_period`, `evidence_site`를
  추가했다. 확인 목록은 사유별 문구를 쓴다(기간이 다름·사업장이 다름·미래 예상·증거 부족
  등). 사유가 없는 과거 기록은 기존 문구를 쓴다.
- R3 표시(미해결 대조 → 확인 목록 → 보고서)는 기존 테스트 그대로 통과한다.

## 5. 남은 한계 (이번 작업에서 고치지 않음)

1. 08의 `생산 스크랩 내부 재투입률 92%`가 E-2-2 `재생 원부자재 비율`로 매핑돼 보고서에
   실린다(내부 재투입은 재생 원부자재와 다른 개념). **고치지 않았다.**
2. 재활용량 3.0톤 오류가 남아 있다(06의 항목 번호를 수량으로 읽음). 초기·후속 E 생성문 모두
   `폐기물 재활용량은 3.0톤`을 서술한다.
3. 지표 기간이 연도만(`2026`)이고 원문이 그 해의 한 달(`2026년 4월`)이면 일치로 본다 —
   모델이 보고 연도만 적는 경우를 위한 것으로, 기존 테스트(`test_explicit_no_incidents_preserves_zero`)
   의미를 유지한다. 반대 방향(연간 미발생 → 월)은 `period_unproven`으로 막는다.
4. 연도 없는 구간(`04-01 ~ 04-07`)만 있는 원문은 기간을 읽지 못해 기간 대조를 하지 않는다.
5. 부정 서술 판정은 규칙 기반이다. 테스트한 구조 변형 밖의 문장은 `interpretation_unknown`으로
   떨어져 0을 싣지 않는 쪽(보수적)으로 동작한다.
6. 한울정밀 세트 전체가 올바르게 동작한다고 볼 근거는 없다 — 위 1·2와 모델 라벨 오류(이전 캐시 09·13)가 있다.
