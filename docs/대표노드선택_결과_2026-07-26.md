## 2. 작업 1 — 코드 부여 불일치 원인 (가설 반증)

**증상**: 동일 hint `Scope 3 온실가스 배출량 연결(일부)`이 2022년은 E-3-2, 2023·2024년은
E-3-1로 갔다. Scope3 값 3,344,082 / 3,136,024가 Scope1+2 후보 풀을 오염시켰다.

**사용자 가설(사전 통보된 확신도 중간)**: `_resolve_kesg_code` 사전 매칭과 LLM
`kesg_code_guess`의 경합. → **반증됨.**

```
resolve_kesg_code('Scope 3 온실가스 배출량 연결(일부)') == ('E-3-2', 0.9, 'exact')
```
사전은 세 노드 모두에 대해 E-3-2를 정확히 돌려준다. LLM 경합도 없다.

**실제 원인** — `ocr_router._backfill_kesg_codes`의 선착순 점유 가드:

1. 첫 번째 metric이 E-3-2를 받는다 → `taken_codes = {'E-3-2'}`
2. 두 번째·세 번째 metric(hint 완전 동일)은 `code in taken_codes`로 **skip** → `kesg_code_guess = None`
3. 코드 없는 metric이 `evidence_graph`로 내려가 `_HINT_TO_KESG` 폴백에 걸린다
4. 그 사전에서 `'온실가스'` → **E-3-1**

즉 중복노드 방지 가드가 다연도 표(같은 hint, 연도별 값)를 중복으로 오판했고,
그 부작용으로 하류 폴백이 다른 코드를 붙였다. 고치기 전에 end-to-end로 재현했다.

**수정**: `taken_codes: set[str]` → `taken_by_label: dict[str, set[str]]`.
라벨(`_normalize_label`)이 같으면 점유 여부와 무관하게 같은 코드를 준다.
다른 라벨의 점유는 종전대로 차단한다(지정폐기물 → E-6-1 유령 중복노드 가드 유지).

회귀: `TestCodeAssignmentConsistency::test_same_hint_always_resolves_to_same_code`(동일 hint 3건 → `{E-3-2}`),
`test_different_label_still_cannot_steal_taken_code`(기존 가드 보존).

## 3. 작업 2 — 공용 선택 함수와 두 호출부

신규 `esgenie/ssot/node_select.py`:

| 함수 | 역할 |
|---|---|
| `select_representative_node(code, nodes, *, report_year=None)` | 대표 노드 1개 또는 `None` |
| `is_derived_hint(hint)` | 파생·비실적 판정(테스트·감사용 공개) |
| `normalize_to_item_unit(code, value, unit)` | `(값, 단위, 플래그)` — 작업 3 |

우선순위(앞에서 갈리면 뒤는 안 본다):

```
1) 파생·비실적 hard 배제        감축·효과·예상·증감·원단위·목표·제로화·회수량 … (21종)
2) 코드별 negative keyword       E-3-1 ← Scope 3·1+2+3 / E-5-1 ← 재활용 …
3) 지표 계열 (신규)              E-6-1 발생량>배출량>처리량 / E-3-1 지역기반 우선 …
4) 세부 분해 (신규)              PPA·녹색요금제 / 매립·소각·미폐기 / 일반·지정 폐기물 …
5) 집계                          합계·총계·총 > 구분어 없음 > 국내(별도)·자회사·사업장
6) 단위 정합                     항목 단위 동일 > 환산 가능 > 그 외 (E-4-1 TJ 우선)
7) 연도                          report_year 근접 — **최후 tie-breaker**
8) 동률/후보 0                   None → 미공시 + confidence_flag
```

호출부 2곳(대칭):

| 파일 | 지점 | 변경 |
|---|---|---|
| `esgenie/ssot/ssot_pipeline.py` | `_merge_ssot_evidence` → `ocr_repr` | `_repr_key` 클로저 삭제, 공용 함수 호출 |
| `esgenie/layer3_detect.py` | `_score_d1_numeric` G5 | `min(compat, key=…)` 삭제, 공용 함수 호출 |

`scripts/inspect_ledger_provenance.py`도 같은 함수를 부르도록 고쳤다. 스크립트가 옛 연도
규칙식을 복제해두면 규칙 교체 후에도 원장에 없는 노드를 `←원장선택`으로 찍어 관찰이

### 8단계(미공시 폴백) — 구현 확인

전 후보가 1·2단계에서 배제되면:
- `select_representative_node` → `None`
- 원장: `result.mapped`에 코드를 **만들지 않는다**(정량 항목에 `"문서 조항 확인"`을 채우면
  미공시가 공시로 위장된다 — 승격 분기에 `if repr_node is None and not text_ids: continue` 추가)
- `confidence_flags[code] += ["no_representative_node"]` + `notes` 1줄
- **노드는 그래프에 그대로 남는다**(폐기 금지 — 감사추적)
- D1: `node is None` → 비교 스킵(오탐 안 냄)

회귀 4건: `TestUndisclosedFallback`.

### 작업 2-3 — `report_year 최근접` 강등

`feature/ledger-provenance`가 넣은 연도 규칙은 7순위 tie-breaker로 내렸다. 주석도 갱신했다.
`tests/test_ledger_provenance.py::TestRepresentativeNodeSelection`의 기대값은 유지되지만
**작동 이유가 달라졌다** — 그 테스트들은 hint 없는 얇은 노드를 쓰므로 3~6축이 전부 동률이라
연도 축까지 내려간다. docstring에 이 사실을 적었다.

`test_ledger_and_d1_pick_the_same_node`은 선택식을 복제하는 대신
`select_representative_node`를 직접 호출한다 — 복제하면 대칭 단언 자체가 무의미해진다.

## 7. 사용자 검증 커맨드 (라이브 1회)

```bash
python3 scripts/inspect_ledger_provenance.py --ticker 012330 --areas E \
        --json outputs/ledger_provenance_012330_v3.json
```

L0+L1만 돌고 L2~L5(LLM)는 타지 않는다 — 비용은 OCR 1회.

**기대값** (§1 표와 동일):

```
[E-3-1] ... 원장 : 396152.0 tCO2eq   (항목 단위 tCO2eq)
[E-4-1] ... 원장 : 7497.0 TJ         (항목 단위 TJ)
[E-5-1] ... 원장 : 1992921.0 ton     (항목 단위 ton)
[E-6-1] ... 원장 : 72463.0 톤        (항목 단위 톤)
[E-7-1] ... 원장 : 150670.0 kg       (항목 단위 kg)
[E-7-2] ... 원장 : 555124.0 kg       (항목 단위 kg)
```

요약 줄 기대값:

```
  선택 규칙 불일치(구조적 D1 오탐 후보): 0개 []
  원장 단위 ≠ 항목 단위: 0개 []
  비교 노드 없음(claim만 존재): 0개 []
```

- `선택 규칙 불일치`는 이제 **구조적으로 0**이어야 한다(두 경로가 같은 함수를 호출).
  0이 아니면 대칭이 깨진 것 = 회귀다.
- `원장 단위 ≠ 항목 단위`는 5개 → **0개** 기대. `⚠단위불일치` 마크가 사라진다.
- `no_representative_node` 플래그는 이 회사 E영역에서 **발생하지 않는다**(12코드 전부 선택 성공).
  뜨면 해당 코드의 후보가 전부 파생·비실적이라는 뜻이므로 hint를 확인해야 한다.

라이브 결과가 위와 다르면 v2 → v3 사이에 OCR 산출물이 달라진 것이므로, 값이 아니라
**어느 축에서 갈렸는지**를 먼저 봐야 한다(`hint` 컬럼이 출력에 그대로 찍힌다).
