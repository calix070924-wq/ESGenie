# 원장 값 공급 경로 수정 결과 (작업0~3)

2026-07-25 · 브랜치 `feature/ledger-provenance`
근거: `docs/역추적_claim오염_경로분리_2026-07-25.md`

## 요약

본문 claim과 D1 비교 노드가 **다른 파이프라인**에서 오던 구조를 세 지점에서 정렬했다.
PR #44(G1~G6)는 그래프 노드만 정화했으므로, 원장(L1) 쪽 경로를 같은 기준으로 맞춘다.

| 작업 | 대상 | 내용 |
|---|---|---|
| 0 | `scripts/inspect_ledger_provenance.py` | 원장 값의 출처를 코드별로 관찰(L0+L1만, LLM 무호출) |
| 1 | `ssot_pipeline._merge_ssot_evidence` | 우선순위 역전 해소 — 무게이트 정규식 값 < 게이트 통과 OCR 노드 |
| 2 | 동上 `ocr_repr` | 대표노드 선택을 D1의 G5(`report_year` 최근접)와 통일 |
| 3 | `dart_client._regex_extract_kesg` | 가드어휘 스킵 + 값 상식범위 |

## 작업0 — 관찰 도구 (라이브 실행 대기)

```bash
python3 scripts/inspect_ledger_provenance.py --ticker 012330 --areas E \
        --json outputs/ledger_provenance_012330.json
```

`pipeline.run`이 아니라 L0(그래프 빌드) + L1(원장)만 조립해 돌린다. **L2 초안 생성·L4 검증
루프를 타지 않아 LLM 호출이 0**이고 비용은 OCR 1회뿐이다.

출력 3종:
1. 코드별 원장 `value/unit/note` → note 문자열로 `[A] DART 정규식` / `[A'] 구조화 API` /
   `[B] OCR 노드` 경로 판정
2. 같은 코드의 그래프 노드 전량(period·value·unit·hint·origin), 원장 선택 노드와 D1 선택
   노드를 각각 표시
3. 요약 — 경로별 항목 수 / **선택 규칙 불일치 코드**(구조적 D1 오탐 후보) / 원장 단위 ≠ 항목
   단위 / 비교 노드 없이 claim만 있는 코드

역추적 문서의 경로 판정표(용수 114,884=[A], Scope3 14,160,000=[B] 등)를 한 번에 확정한다.
**작업1~3은 이 결과와 무관하게 구조적으로 정당하지만, 0의 결과에 따라 남은 오염의
우선순위가 바뀔 수 있다.**

## 작업1 — 우선순위 역전 해소

무게이트 정규식 값이 G1~G6를 통과한 OCR 노드를 이기던 `if code in result.mapped: continue`를
경로 티어 판정으로 바꿨다.

- `dart_client.SOURCE_DART_REGEX` 태그를 정규식 추출 항목에만 부여
- 태그가 붙은 항목에 대응 OCR 노드가 있으면 **OCR 값으로 대체**, 원값은 `superseded_value`로
  보존하고 `confidence_flags`에 `regex_superseded` 기록 + `notes`에 전후값 로그
- **태그 없는 값(구조화 API·사외이사 재계산)은 강등 대상이 아니다** — 라벨링 §4-1이 정확하다고
  확인한 대조군을 건드리지 않는다
- OCR 노드가 없으면 정규식 값 유지 → 커버리지 손실 없음

## 작업2 — 대표노드 선택 통일

```python
# 이전: max(period, confidence)  — 미래 노드를 실적으로 선택
# 이후: min(|period - report_year|, -period, -confidence)  — D1의 G5와 동일
```

다연도 노드를 가진 코드에서 **원장은 최신 노드, D1은 보고연도 노드**를 골라 데이터가 옳아도
claim ≠ node가 되던 구조적 오탐이 사라진다. `graph.report_year`가 없으면 기존 동작으로 폴백.

## 작업3 — 정규식 경로 최소 방어선

`re.search` 첫 매치 무조건 채택 → `re.finditer`로 **가드어휘·상식범위를 통과하는 첫 매치**.
패턴 자체는 그대로 두어 커버리지 손실을 최소화했다.

- **가드어휘** `목표·감축량·전망·예상·누적·전환량·집약도·계획·로드맵` (L0 G1과 같은 어휘)
- **가드 문맥**(`_guard_window`) = 매치 구간 + **직전 숫자까지**의 앞부분.
  고정 폭 되돌아보기는 옆 행의 '목표'가 정상 실적 행까지 차단해 과차단을 냈다
  (`용수 사용 절감 목표 5,000 톤 · 용수 사용량 1,992,921 톤` → 값 없음). 앞쪽 숫자는 다른
  셀·행의 값이므로 그보다 앞의 어휘는 지금 집은 값의 레이블이 아니라는 근거로 경계를 잡았다.
- **상식범위**(`_KESG_SANITY` / `_UNIT_SANITY`) — 비율 0~100, 재해율 0~10, E-3-1 tCO2eq 하한 100 등.
  범위 미정의 코드는 통과(보수적).

### 전후 비교 (단위 테스트 기준)

| 입력 | 구(첫 매치) | 신(가드 후) |
|---|---|---|
| `온실가스 목표 감축량(Scope1+2) 114,884 tCO2eq … 총 온실가스 배출량 3,560,074 tCO2eq` | **114,884** | 3,560,074 |
| `온실가스 배출 원단위 4 tCO2eq … 총 온실가스 배출량 3,560,074 tCO2eq` | **4.0** | 3,560,074 |
| `재생에너지 사용 비율 320 % … 전환율 12.9 %` | **320.0** | 12.9 |
| `용수 사용 절감 목표 5,000 톤 · 용수 사용량 1,992,921 톤` | **5,000** | 1,992,921 |
| `총 에너지 사용량은 9,075 TJ` (정상) | 9,075 | 9,075 |
| `용수 사용량은 1,992,921 톤` (정상) | 1,992,921 | 1,992,921 |

## 검증

- 신규 `tests/test_ledger_provenance.py` **12건 통과** — 작업1(3)·작업2(3)·작업3(6).
  각 작업에 **음성 테스트**를 뒀다: 태그 없는 값 미강등 / OCR 없을 때 정규식 값 유지 /
  report_year 없을 때 기존 폴백 / 정상 텍스트 불변 / 인접 행 과차단 방지.
- 전체 스위트 **684 passed, 8 skipped** (수정 전 672 + 신규 12, 무회귀).
  `pytest tests/ -q --ignore=tests/test_ui_apptest_smoke.py --ignore=tests/test_ui_tabs.py`
- 남은 2 failed = `test_pipeline_e2e`의 OCR 의존 케이스. **HEAD에서도 동일하게 2건 실패**함을
  파일 스왑으로 대조 확인 — 샌드박스 OCR 차단에 따른 환경 한계이며 이번 수정과 무관.
- 작업3의 전후 비교는 구 로직(`re.search`)을 같은 입력에 직접 돌려 대조했다. 초기 픽스처 2건은
  다른 패턴이 먼저 정답을 집어 **가드를 타지 않는 무효 테스트**였고, 오염값이 먼저 매치되도록
  교체해 실제 차단을 확인했다.
