## 3. 원인과 변경 규칙(문서명·회사명·정답 수치 분기 없음)

1. **C1 개정 연도**(`ocr_router._HEADING_CODE_RE`, `_standard_refs`, `_standard_mask`)
   - 규격 번호 뒤 콜론(공백·전각 포함) + 연도를 번호로 붙인다. 개정판을 쓰는 이름(ISO·IEC·GRI·OHSAS·KS 등)만 해당하고, `년`·날짜가 이어지면 붙이지 않는다.
   - 기간은 제목·서술·열 머리 모두 이 번호를 가린 문구에서 읽는다. 사업장은 원문에서 읽는다.
   - 0 바로 뒤 괄호가 규격 식별자와 `기준`류 낱말뿐이면 사실성 판정에서 뗀다.
   - 판정한 구간의 역할(period·site·standard_ref)과 위치를 `scope_spans`로 남긴다.
2. **C2 회계연도·분기**(`_date_spans`, `_fiscal_definitions`)
   - `FY2026`·`FY26`·`Q1`·`N분기`를 기간 표기로 읽는다. 실제 구간은 문서 정의(`FY2026 = 2026-01-01~2026-12-31`, `FY26 = FY2026`)나 명시 월(`2026년 1분기(1~3월)`)이 있을 때만 정한다.
   - 정의가 없으면 `undefined` 사유로 SOURCE_ONLY다. 원문 쪽 텍스트도 정의 검색에 쓴다.
   - `FY 2026.04`는 종전대로 실제 월이다.
3. **C3 규격 실적 제목**(`_heading_kind` → `standard_heading`, `_zero_heading`)
   - 규격 이름·번호를 뗀 나머지가 이 지표의 범위 낱말뿐이면, 그 제목의 사업장·기간을 쓰는 새 절이다. 위 머리말에서 빠진 범위는 채우지 않는다.
   - 규격 식별자 + 점선·쪽 번호 줄(목차)과 다른 대상의 규격 제목은 범위를 주지 않는 경계다.
4. **E-2-2 충돌 어휘**(`evidence_graph._ASSIGNMENT_NEGATIVE_KEYWORDS`, 보강 단계 동일 적용)
   - E-2-2는 재활용 원부자재 사용량 ÷ 원부자재 사용량이다. 공정에서 발생한 스크랩의 재투입·발생량·반출은 분모가 달라 연결하지 않는다.
5. **표 칸 라벨 근거화**(`_table_cell_label`)
   - 인용의 표 행을 쪽 텍스트에서 하나로 찾은 뒤, 0 판정과 같은 머리글 확인 규칙으로 열 머리를 구한다.
   - 모델 라벨이 열 머리(또는 그 중심어)를 담지 않으면 원문 행 라벨·열 머리로 쓴다. 모델 라벨은 `label_check` 감사 기록에 남긴다.
   - 기간·열 역할·집계 축·일반 머리(`값`)·반복 값은 보지 않는다.
6. **값이 빈 행의 부정 서술**(`_negation_zero_from_null`)
   - 원문과 대조된 인용에 같은 지표의 명시적 미보유·미발생 서술이 있고, 0 판정이 그 서술을 보존할 때만 0을 싣는다(`value_recovery`).
   - 숫자 0 칸·빈 칸·미확인·해당 없음·목표에서는 만들지 않는다.
7. **회사 답변**(`claims._stated_scope`·`_answer_context`·`trace_claim_values`, `mapping._stated_claim_scope`)
   - 답변 행의 명시 기간·사업장·분모, 문항 ID·요청 내용·작성 메모(문서 ID)를 읽는다. 같은 값의 다른 지표 근거를 찾을 때는 메모가 가리킨 문서를 먼저 보고, 없으면 재활용 관련 지표만 본다.
   - 부분값 증빙과 같은 기간·사업장을 적고 분모가 없을 때는 둘로 나눈다.
     - 다른 지표 값을 옮긴 근거가 있으면 `not_comparable`로 두고 양쪽 원문 계산식을 함께 적는다.
     - 그 근거가 없으면 `scope_unconfirmed`(분모 미기재)로 둔다. 숫자만으로 충돌을 확정하지 않는다.
   - 회사 답변 원문에서 읽은 경계(`scope_from=answer_text`)에만 적용한다. 호출부가 동일 범위를 명시한 주장(HMC 통제)은 기존 비교 그대로다.
8. **SOURCE_ONLY 소비**(`audit_trace.build_data_points`, `mapping`, `layer2_rag`, `ssot_pipeline`, `excel_exporter`)
   - DataPoint 비교·회사 답변 일치/충돌·기본 28개 밖 답변에서 `scope_unconfirmed`와 사유를 쓴다.
   - LLM 원장 줄·의사 청크·근거 청크에 `[범위: …] [상태: 요청 범위 실적 미확정 …]`를 싣고, 넘어서는 서술을 금지하는 지시를 더한다.
   - 데이터시트에 `측정 범위`·`범위·확정 상태` 열을 추가했다. 기존 열 순서는 그대로다.
9. **본문 대조 표시**(`layer6_report.annotate_generated_text`·`annotate_summary_text`)
   - 생성 문장마다 세 가지를 찾아 같은 문장 뒤에 `[검토: …]`를 붙인다.
     - 인용 근거에서 찾지 못한 숫자(날짜·항목 코드·묶음 인용 번호 제외)
     - 미확정 값을 상태 없이 단정한 문장
     - 부분값을 전체·전사·연간·합산으로 넓힌 문장(넓힘을 부정한 문장은 제외)
   - 모델 원문은 영역 검증 결과에 그대로 둔다. 보고서 PDF 글꼴이 그리는 ASCII 괄호를 쓴다(〔〕는 PDF에서 빠짐).
10. **응답서 PDF**(`exporters/pdf._evidence_chunks`)

- **0 대표값 규칙**: main 규칙상 0은 단위 `건`인 위반·사고 지표만 대표값이 된다(산업재해율 0‰은 노드·확인 목록에만 남음). 기존 설계이며 바꾸지 않았다.
- 11번은 모델 응답이 실행마다 0·null·조항으로 달랐다. 셋 모두 원문 사실 보존 또는 0 복원으로 처리되지만, 조항으로 오면 수치 0 노드는 없다.
- 05 메모 연결은 메모가 문서 ID를 적은 경우에 강하다. 메모가 없으면 재활용 관련 지표의 같은 값만 후보로 본다.
- §5 C2는 FY·분기 정의가 같은 쪽 텍스트에 있을 때만 읽는다. 다른 쪽·문서의 정의, 기존 설정(회계연도 설정값은 현재 없음)은 범위 밖이다.
