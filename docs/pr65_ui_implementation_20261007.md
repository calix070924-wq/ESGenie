- React 웹 작업 화면은 기존 Python pipeline / responder / EvidenceLink를 사용한다. Streamlit 경로도 유지한다.

## 구현

자료 준비에서 여러 파일 업로드, 파일명 검색과 페이지 이동, 분석 포함·제외, 증빙/회사 작성 답변 구분, 행에서 교체를 제공한다. 암호·손상 파일은 실패 사유와 교체 동작을 행에 남긴다. 교체 전 원본은 버전별로 보관하고, 기존 답변의 파일명·버전·페이지를 유지한다. 분석 도중 입력을 잠그며 실패 시 이전 결과를 보존한다.

답변 목록에 저장된 값·입력 방식·담당자 검토 상태·파일명·페이지·범위를 표시한다. 분야·검토 상태·검색·페이지 상태는 상세 화면을 열었다 돌아와도 유지한다. 상세 화면은 왼쪽 편집과 오른쪽 실제 원문 페이지를 나란히 배치한다. 새 분석값을 살펴보는 동작과 값·단위·범위·근거를 적용하는 동작을 분리한다. 원문 페이지를 담당자가 직접 근거로 연결할 수도 있다.

저장과 검토 완료를 분리한다. 빈 답변은 자료 부족 사유를 남겨 검토 완료할 수 있지만, 엔진의 자료 판단은 그대로 남는다. 변경 기록에 이전/새 값·범위·근거·수정 이유를 표시한다. 미저장 상태에서 단계·문항·목록·새 작업으로 이동하면 저장하고 이동 / 수정 버리고 이동 / 계속 작성을 제공한다. 브라우저 닫기 경고 및 로컬 임시 작성 내용 복원도 제공한다.

자료 변경은 연결된 문항을 식별해 재검토 표시를 한다. 재분석에서 담당자 입력은 유지하고 새 자동값을 비교 대상으로 제공한다. 무관한 문항의 검토 완료를 유지한다. 이전 분석 JSON과 자동값 변경 이력을 보관한다. 재분석 전에는 이전 응답서 경고를 표시하고 모든 내려받기를 서버에서도 막는다.

응답서 미리보기·Excel·PDF는 동일한 저장 답변·단위·범위·근거·담당자 검토 상태를 사용한다. 엔진의 원 판정은 별도로 유지하며 부족/범위 확인 사유도 함께 출력한다. 검토가 남아도 검토용 파일을 생성한다. 직접 PDF 내려받기 및 Excel/PDF/근거 원본/이전 분석 기록을 포함한 ZIP 묶음을 제공한다. Excel의 사용자 텍스트는 수식으로 실행되지 않게 처리한다.

## 검증

- 전체 오프라인 회귀: 5,497 통과 / 12 건너뜀. 12개는 비공개 실보고서가 필요한 기존 검사다. 실행 기록은 `validation/pr65-ui-20261007/regression.xml`에 있다.
- 최종 웹 서버/저장/근거/출력 관련 검사: 19 통과. PR71 수치·범위 회귀를 함께 실행한 최종 관련 검사 188 통과. 전체 검사 후 추가한 원본 버전·이전 분석 기록·후보값 범위·원문 직접 연결 보강을 포함한다.
- 실제 Chrome 브라우저: 3 시나리오 통과. 미저장 세 가지 선택, 목록 검색 복원, 실제 Excel/PDF 내려받기, 실제 PDF 업로드→분석→수정→완료→교체→재분석, 이전 원문 확인, 관련 문항만 재검토를 검증했다.
- 23개 긴 파일명/문항과 320·375·768·1024·1440px 목록/상세에서 가로 넘침을 검사했다.
- TypeScript, 프로덕션 빌드, Prettier 검사 통과.
- 출력 값·단위·범위·근거·상태·메모를 Python에서 Excel 셀 및 PDF 추출 텍스트와 대조했다. PDF를 PNG로 렌더링해 한글·표 경계·페이지를 시각 확인했다.
- 브라우저 자동화의 분석 어댑터는 실제 업로드 PDF를 로컬에서 읽어 결정적으로 반환한다. 외부 AI 호출 결과를 가장하지 않는다. 별도로 생산 엔진 adapter의 입력 분리와 엄격한 오류 처리, PR71 판정 회귀를 검사했다.

## 제한 사항

- 이번 검증에서 외부 AI/OCR 서비스로 실기업 비공개 파일을 전송하거나 정확도를 다시 측정하지 않았다. 실제 서비스 분석은 설정된 연결을 사용하는 기존 pipeline에 연결되어 있으며, 운영 자료로 정확도/처리시간 검증은 별도 필요하다.
- 현재 웹 작업 저장은 한 컴퓨터의 로컬 워크스페이스다. 로그인·여러 담당자 동시 편집·배포·고객사 포털 제출은 포함하지 않는다.
- 지원 업로드는 PDF/PNG/JPG/JPEG, 파일당 20MB·200쪽, 한 작업 최대 200개·이전 원본 포함 100MB다. 회사 작성 답변은 기존 SAQ 파서와 호환되는 문서를 사용한다.
- PDF 원본은 실제 페이지 이미지로 표시하고 좌표가 있는 경우 근거 영역을 강조한다. 브라우저에서 직접 PDF를 편집하는 기능은 없다.
