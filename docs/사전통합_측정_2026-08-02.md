# 코드 배정 사전 통합 오프라인 측정 (2026-08-02)

## 결론

`kesg_items` exact alias를 코드 배정의 단일 출처로 사용했을 때 신규 K-ESG 배정은
1,978건, 자동·수동 규칙으로 확인한 명백 오배정은 89건(4.50%)이었다. 중단 기준 10%보다
낮아 오프라인 관문은 **PASS**다. fuzzy 허용은 exact 대비 4건만 추가했으므로 생산 정책은
재현성과 정밀도를 우선해 **exact-only**로 확정했다.

측정 명령:

```bash
python3 scripts/measure_code_assignment.py --sample-limit 300
```

라이브 API는 호출하지 않았다.

## 측정 조건과 기준선

- 시작점: `fb8874ef4cbb43f7ca0082379319b4e8946da6bf` (`origin/main`, PR #57 병합)
- 입력: `data/_cache/ocr/*.json` 중 5개사 LLM 원본 응답
- 중복 제거 키: 회사·hint·value·unit·period·guess
- 고유 metric: 22,310건
- legacy: 시작점 커밋의 `_HINT_TO_KESG`와 당시 G1/G3를 스크립트가 읽어 재현
- exact: 현재 `kesg_items.resolve_kesg_code`의 exact 결과 + 동일 G1/G3
- fuzzy: exact와 같은 게이트에서 fuzzy 후보까지 허용한 비교군
- `pymupdf`: 설치 명령을 직접 실행했고 1.27.2.3이 이미 설치되어 있음을 확인
- 구현 전 신규 테스트: 3 passed, 11 failed. 실측 7개 hint는 모두 `None`이었다.
- 기존 G1~G6 기준선: 20 passed

legacy가 GRI 번호 같은 비 K-ESG 문자열도 반환하던 경우는 배정 성공으로 세지 않았다.

## 오배정 점검

요청된 네 유형을 다음처럼 검사했다.

- Scope 1/2/3 혼동: Scope 표기와 알려진 Scope 3 카테고리명이 반대 코드에 붙는지
- 비율↔절대량: `%`/`‰`와 코드 정의 단위가 반대인지
- 원단위: hint 또는 unit의 `원단위`, `집약도`, `intensity`, `/억원`
- 다른 축: 매출 또는 명/인 단위의 직원·인원·이사 수치가 E 코드에 붙는지

exact 신규 1,978건 중 명백 오배정은 89건(4.50%)이었다.

| 유형 | 건수 | 표본 |
|---|---:|---|
| 내부거래위원회 운영→G-6-2 내부거래 공시 | 45 | 내부거래위원회 개최 횟수 |
| Scope 3 카테고리→E-3-1 | 32 | 다운스트림 임대자산 온실가스 배출량 |
| 위원회 출석률→G-1-2 사외이사 비율 | 10 | 사외이사후보 추천위원회 참석률 |
| 다른 축 수치→E 코드 | 2 | ESG위원회 독립이사 참석자 수 |

이 표식은 측정 관문을 위한 보수적 오류 상한이다. 비율↔절대량과 원단위 신규 오배정은 G1/G3에서
차단되어 0건이었다. 발견된 89건은 10% 중단 기준 이하지만, 최종 원장에서는 기존 중복가드와
대표노드 선택 결과도 함께 확인해야 한다.

## exact vs fuzzy

fuzzy 허용 시 exact 대비 추가는 신한지주 4건뿐이었다.

| hint | exact | fuzzy |
|---|---|---|
| 이사회 평균 참석률 | None | G-2-1 |
| 평균 참석률 (서로 다른 값 3건) | None | G-2-1 |

이번에 `이사 평균 참석률`을 근거 기반 exact search term으로 추가했으므로 실제 목표 표현은 fuzzy
없이 회복된다. 범용 `평균 참석률`까지 자동 배정할 이득이 작아 fuzzy는 거부한다.
